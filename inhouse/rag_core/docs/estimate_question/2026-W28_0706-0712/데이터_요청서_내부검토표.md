# 예상 질문

## 문서 목적 / 표기 체계
- 이 검토표의 목적은 무엇이며 어떤 근거 문서에 기반하는가?
- 우선순위·보유상태·자체수집 여부는 각각 어떤 기호로 표기되는가?

## 선결 사항
- 0-1 항목은 무엇을 요청하는 것이며 왜 최우선(🔴)인가?
- 희토류에 포함되는 원소·산화물로 어떤 것들이 예시되었는가?
- 0-1이 미확정일 때의 영향은 무엇인가?

## A. 진단모델 관련 요청 항목
- A-1부터 A-8까지 항목명은 각각 무엇인가?
- A-2(세계 소비량)의 현재 보유 상태와 자체수집 판정은?
- A-4(REE 주간가격)는 현재 무엇을 보유하고 있으며 왜 자체수집 불가인가?
- A-6(생산·매장 장기 시계열)의 현재 보유 범위는 어디까지인가?
- A-7(월간 국가별 수입통계)의 용도는 무엇이며 현재는 어떤 주기만 보유하는가?
- A-8(ESG/인권 지수)은 어떤 공개자료로 구성할 수 있는가?

## B. 예측모델 관련 요청 항목
- B-1은 무엇이며 왜 🔴 CRITICAL로 분류되었는가?
- B-2(한국 GDP·산업생산)의 현재 보유 상태는 어떠한가?
- B-3은 왜 자체수집 불가인가?
- B-4의 공개 소스로 무엇이 제시되었는가?

## 종합 분류
- 🟢 자체수집 가능 6건은 무엇인가?
- 🟡 부분 가능 3건은 무엇인가?
- 🔴 발주처/상용 필수 4건은 무엇이며 각각의 성격(결정사항/내부기록/유료)은?
- 최종적으로 발주처에 요청할 항목 수는 몇 건으로 축소되었는가?

## 인증키 / 다음 단계
- 자체수집 착수를 위해 발급이 필요한 서비스 2개는 무엇이며 비용·약관 조건은?
- 키가 필요 없는 소스는 무엇인가?
- 인증키 확보 후 즉시 착수하겠다고 밝힌 작업 2가지는?
