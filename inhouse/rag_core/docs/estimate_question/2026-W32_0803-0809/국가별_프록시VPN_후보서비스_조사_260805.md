# 예상 질문

## 조사 성격 / 대상
- 이 조사에서 실제 계약·구매·테스트를 수행했는가?
- 국가별 IP 프록시 검토 대상이 된 기관은 어디어디인가?
- 국가 IP 프록시로 우회 가능한 유형과 그렇지 않은 유형은 어떻게 구분되는가?

## 대상별 차단 성격 진단
- 필리핀 MGB의 차단 성격(WAF 403)과 프록시로 뚫릴 가능성 평가는?
- 호주 DISR의 차단은 왜 "중간" 가능성으로 평가되었는가?
- 페루 MINEM의 HTTP 418은 어떤 패턴으로 해석되었는가?
- 중국 GACC 상세가 "불확실"로 평가된 이유는 무엇인가(지문·행동 기반 봇탐지)?
- MGB·MINEM의 현재 우선순위가 낮은 이유는 무엇인가?

## 후보 서비스 비교
- 프록시 시장의 3개 티어는 각각 무엇이며 대표 서비스는?
- 엔터프라이즈 티어(Bright Data·Oxylabs)의 GB당 가격대와 특징은?
- 미드마켓 티어(Decodo·SOAX·NetNut)의 가격대와 강점은 무엇인가?
- 저가형 티어에서 IPRoyal이 갖는 구조적 이점은 무엇인가?
- 필리핀·페루 최저가권 서비스로 언급된 것은 무엇이며 단가는?
- 중국 IP 풀 규모가 가장 큰 서비스는 어디이며, 그 규모가 성공률을 보장하지 못하는 이유는?

## 사용량 / 비용
- 우리 프로젝트의 예상 사용량 수준은 어느 정도인가?
- 사용량 상한선으로 제시된 사례(MGB 지방청 214개 링크)는 무엇인가?
- 왜 GB 단가보다 최소 결제 단위·트래픽 만료 여부가 더 중요한가?
- 예상 비용 규모는 대략 얼마로 추정되는가?
- 월정액 구독형이 우리 사용 패턴에 불리한 이유는?
