# 예상 질문

## 개요 / 용도
- 5대 광종의 HS코드 바스켓은 어떤 작업들에 공통으로 사용되는 단일 정본인가?
- HS 바스켓은 공급망의 어느 단계까지 포괄하는가(원광~응용품)?
- HS 매핑 정본 파일의 경로와 전체 행 수, 그중 핵심 코드 수는 각각 몇 개인가?

## 광종별 코드 수 / 구성
- 구리·니켈·코발트·리튬·희토류 각각 몇 개의 HS 10단위 코드로 구성되어 있는가?
- 핵심 161개 코드는 광종별로 어떻게 배분되는가(CU 88·NI 36·CO 15·LI 13·REE 9)?
- 구리 바스켓에서 HS 74류가 차지하는 비중(85/88개)은 어느 정도인가?
- 구리 바스켓에서 코드 수가 가장 많은 HS 호는 무엇인가(7409 판·시트 18개, 7403 괴 11개)?
- 니켈 바스켓에 황산니켈(2833.24)·페로니켈(7202.60)·니켈 담지 촉매(3815.11)가 포함된 이유는?
- 코발트 바스켓에 초산코발트(2915.29)·코발트계 안료(3206.49) 같은 화학 품목이 들어간 근거는?
- 리튬 바스켓의 전구체계(2841.90) 5개 코드는 무엇을 포괄하는가?
- 희토류 바스켓 9개 코드의 구성은 어떻게 되는가(2805.30×6, 2846×2, 8505.11×1)?

## 광종별 포괄 범위(공급망 단계)
- 구리(CU)는 광석(2603)에서 가공품까지 어떤 단계로 이어지는가?
- 니켈(NI)의 포괄 범위에 화합물·촉매·전지까지 들어가는 이유는?
- 리튬(LI)은 광물(2530)에서 리튬이온전지(8507)까지 어떤 흐름으로 매핑되는가?

## 근사 매핑 / 한계
- 희토류를 "근사 매핑"이라고 부르는 이유는 무엇인가?
- 2805.30·2846 코드가 네오디뮴 단독 물량과 차이가 나는 이유는?
- 영구자석(8505.11)은 어떤 기준으로 집계되며 해석 시 유의점은?
- 이차전지(8507.60)·양극 전구체(2841.90) 같은 복합재 코드는 왜 순수 리튬 환산량과 구분해 해석해야 하는가?
