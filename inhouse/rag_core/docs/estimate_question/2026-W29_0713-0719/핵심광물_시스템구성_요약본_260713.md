# 예상 질문

## 시스템 구성 / 아키텍처

- 수집기는 어떤 환경(DMZ·클라우드)에 어떤 형태로 배치되며 요구 자원은 어느 정도인가(CPU 1~2코어)?

- 일일 반입 절차 4단계(수집→번들→반입→처리)는 각각 어디에서 수행되는가?
