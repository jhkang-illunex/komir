# 비축 부족량·비축일수 계산 방법론

이 문서는 실비축 현황을 제공하지 않는 계산 정의다. 수치 답변에는 기준일이 같은
현재재고와 목표재고, 그리고 산정 기간이 명시된 일평균소비량이 모두 확인되어야 한다.

## 입력값과 단위

| 입력값 | 단위 | 기준 |
| --- | --- | --- |
| 현재재고 | 톤 또는 kg | 기준일의 실제 가용 재고 |
| 목표재고 | 현재재고와 같은 단위 | 같은 기준일의 목표 재고 |
| 일평균소비량 | 톤/일 또는 kg/일 | 명시한 관측 기간의 평균 |

현재재고와 목표재고는 같은 질량 단위로 환산한다. 일평균소비량의 질량 단위도
재고와 맞춘다.

## 계산

부족량은 목표보다 현재재고가 적을 때만 양수로 표시하는 산술 정의로,
`max(목표재고 - 현재재고, 0)`이다. 목표를 이미 충족했을 때 음수 부족량을
표시하지 않는다.

비축일수는 `현재재고 / 일평균소비량`이다. 분모가 0이거나 확인되지 않으면
비축일수를 계산하지 않는다.

## 근거와 한계

`documents/산출물/2026-W28_0706-0712/mineral_risk_model_v1.md`의 보조 지표
`inv_days[m,w]`는 재고일수를 `거래소 재고 / 일평균 소비`로 정의한다. 이 방법론은
그 정의를 비축 현황 질의의 단위·입력값 계약으로 사용한다. 현재 서비스에는 리튬의
현재재고, 목표재고, 일평균소비량 실측 원천이 없으므로 이 문서만으로 실제 부족량이나
실제 비축일수를 산출할 수 없다.
