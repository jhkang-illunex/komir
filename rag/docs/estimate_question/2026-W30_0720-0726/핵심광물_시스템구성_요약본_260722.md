# 예상 질문

## 시스템 개요 / 구성
- 시스템은 몇 개 모듈이 몇 대의 서버에 어떻게 나뉘어 동작하는가?
- 수집 서버와 분석 서버의 역할 차이는 무엇인가?
- 5개 모듈(수집기·전처리기·지수 추정기·진단기·수입 추정기)의 기능과 주기는?
- 모든 결과가 "근거와 함께" 발행된다는 것은 구체적으로 무엇을 뜻하는가?

## 수집기 배치와 데이터 반입
- 수집기는 어디에 어떤 형태로 배치되며 요구 자원은 어느 정도인가?
- 분석 서버가 폐쇄망인 이유와 그 보안상 이점(공격면 한정)은?
- 분석에 쓰는 LLM은 어디에 있으며 외부 API 의존은 어떻게 되는가?
- 일일 반입 절차 4단계(수집→번들→반입→처리)는 각각 무엇인가?
- 같은 번들을 다시 넣어도 중복 처리되지 않는 성질을 무엇이라 하는가?

## 데이터 흐름과 품질 관리
- 주간 체인과 월간 체인은 각각 언제 돌며 어떤 순서로 진행되는가?
- 경보 단계 컷의 기준기간과 "절대 눈금"의 의미는?
- 지정학 지수가 수입액 예측에 기여한다는 근거는 무엇인가?
- GKG 재정제 방식(규칙기반 4라운드 + LLM 이중검증)과 관련성 개선 수치는?
- LLM 1차 판정과 2차 재확인의 관점 차이는 무엇인가?

## 지정학 위기지수
- 지수 산출에 쓰이는 가중 요소 4가지는 무엇인가?
- 정제 전후 이벤트 건수는 각각 얼마이며 무엇을 걸러냈는가?
- 정규화 앵커(P90=88 동결)를 쓰는 이유는?
- 지수는 어떤 3개 주기로 산출되는가?
- v2 정밀화에서 개선된 3가지(코퍼스 총량 보정·지속성 감쇠·근사중복 제거)는?
- NB2 강도모델을 쓰는 근거가 되는 이벤트의 실측 특성은?
- isotonic 사후 보정은 무엇을 확보하기 위한 것인가?

- 선형 구조가 설명가능성에 주는 이점은?
