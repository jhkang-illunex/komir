# 예상 질문

- manifest.parquet, geo_events.parquet, geo_index.parquet 각각은 어느 계층의 산출물인가?

## 이벤트 추출(LLM)
- GeoEvent 스키마에 포함된 필드는 무엇이 있는가(예: severity, direction, confidence 등)?

## 지수 산출 공식
- 지정학 위기지수 산출 공식(event_score, index)의 구성 요소는 무엇인가?

- time_decay(반감기)는 주간/월간 지수에서 각각 얼마로 설정되어 있는가?
- 지수 정규화는 광종별로 어떤 방식(0~100 스케일)을 쓰는가?

## 검증(백테스트)
