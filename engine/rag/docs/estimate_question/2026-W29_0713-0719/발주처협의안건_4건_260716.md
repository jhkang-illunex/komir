# 예상 질문

## 배경 / 위상
- 이 안건서는 어떤 후속 조치에서 도출된 것인가(2026-07-13 방법론 점검)?
- 기존 자료협조 목록(설계 정본 v1 §12의 8건)과 이 4건은 어떤 관계인가?
- 4건의 안건은 각각 무엇이며 핵심 목적은 무엇인가?

## 안건 1 — 수급위기 에피소드 사례 목록
- 학습 라벨(수급동향지표)이 이미 있는데도 위기 사례 목록이 추가로 필요한 이유는?
- 수행사가 1차로 구축한 대리 라벨은 무엇이며 어떤 광종에서 선행성이 실증되었는가(AUC 0.90~0.99)?
- 대리 라벨의 한계는 무엇인가(가격 경로만 포착)?
- 요청하는 에피소드 목록의 형식과 규모는 어떻게 되는가(10~20건, 광종·시점·등급·사유)?
- 예시로 제시된 역사적 위기 사례는 무엇인가?
- 자료 제공이 늦어지면 어떤 문제가 생기는가?

## 안건 2 — 미탐:오탐 비용 비율
- 경보 임계의 최적점이 통계가 아니라 정책 판단이라는 주장의 근거는?
- 임계를 낮추면 미탐·오탐은 각각 어떻게 변하는가?
- 수행사가 이미 실증 완료한 것은 무엇인가(h=0~3개월 성능표)?
- 현행 허위경보율 수준은 얼마인가(1.8% 이하)?
- 비용 비율 합의는 어떤 형식으로 요청되는가(예: 5:1, 희토류 10:1)?
- 합의된 비율이 왜 '계약적 근거 문서'가 되는가?
- 결정이 늦어질 경우 운영은 어떻게 되며 무엇을 감리에 제시하기 어려워지는가?

## 안건 3 — 구리(CU) 경보 해석 방침
- 구리에서만 경보와 가격 변동성 지표가 역방향으로 나타난 현상은 무엇으로 설명되는가?
- 2020~26년 구리 변동성 급등 3건은 각각 어떤 원인이었는가?
- 실제 수급 사건(2024-05 숏스퀴즈)이 변동성 지표로 포착되지 않았다는 것은 무엇을 시사하는가?
- 대안 검정에서 구리의 수급 신호는 어떤 지표에서 더 잘 나타났는가?
- 승인 요청 문안의 핵심 주장은 무엇인가?
- 발주처가 결정해야 할 사항 2가지는 무엇인가?

## 안건 4 — 품목(HS) 수준 예측
- 현행 예측의 단위는 무엇인가(광종 총량 5광종 × 12개월)?
- 품목 수준 세분화의 단위와 규모는 어떻게 되는가(HS 4단위, 광종당 3~19개 품목군)?
- bottom-up 방식이 권고되는 이유는 무엇인가(총량 자동 정합, 총량 정확도 동급)?
- 품목 예측이 필요하다고 판정될 경우와 불필요하다고 판정될 경우 각각 어떤 후속 작업이 생기는가?
- 확인 요청 시 함께 정해야 할 항목은 무엇인가(대상 광종·품목 범위·화면 요구사항)?
