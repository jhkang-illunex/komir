# 예상 질문

## 평가 원칙 / 범례
- 이 평가의 대상 문서와 분류 기준(🟢/🟡/🔴)은 무엇인가?
- 할루시네이션 배제를 위해 어떤 원칙을 적용했는가?

## 🟢 자체 수집 가능 항목
- B-1(월간 관세청 수출입통계)과 A-7(월간 국가별 수입)은 어떤 API로 수집 가능한가?
- 관세청 OpenAPI는 어떤 단위(HS 자릿수·국가·기간)로 조회 가능하며 엔드포인트는?
- 관세청 데이터는 언제 전월분이 현행화되는가?
- B-2(한국 GDP·산업생산)는 어떤 API로 수집하며 이용 조건은?
- A-6(세계 생산·매장 장기 시계열)의 USGS 소스 3종은 무엇이며 각각 어느 시점부터인가?
- A-1·A-3(지정학·가격급등 이벤트)은 어떤 방식 두 가지로 확보하는가?

## 🟡 부분 수집 가능 항목
- A-2(세계 소비량)에서 활용 가능한 소스(USGS·산업협회·IEA·EU SCRREEN)는 무엇이며 한계는?
- 구리·니켈·코발트의 대표 산업협회는 각각 어디인가?
- A-8(ESG/인권 지수)이 "부분"인 이유는 무엇인가?
- B-4(배터리·EV 수요지표)에서 공개인 부분과 유료 가능성이 있는 부분은?

## 🔴 자체 수집 불가 항목
- 자체 수집이 불가한 4건은 무엇이며 각각의 사유는?
- 0-1(희토류 1종 특정)이 데이터 문제가 아니라고 보는 이유는?
- A-4(REE 주간가격)가 불가인 이유와, 이미 보유한 대체 데이터는?
- A-5(과거 경보 발령 이력)는 왜 발주처만 제공 가능한가?
