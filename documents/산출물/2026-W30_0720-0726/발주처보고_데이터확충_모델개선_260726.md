## 1. 요약

1. **데이터 확충 완결**: 무료·자동수집 가능한 외부 데이터를 전수 조사·검증하여
   수집 완료했습니다. 시스템 보유 지표 데이터가 약 **16배**(월간 지표 385→6,419행),
   시계열 데이터가 약 **6배**(3,373→20,563행)로 확대되었고, 전 수집 경로가 주간/
   월간 자동 수집(cron)에 편입되었습니다. **남은 것은 유료·비공개 데이터뿐**이며
   4장에 협조 요청 목록으로 정리했습니다.
2. **모델 성능 개선**(전 구간 실데이터 백테스트 검증):
   - 12개월 수입물량 예측 오차 **10% 감소**(29.3→26.3%), 수입단가 예측 오차
     **10% 감소**(20.0→18.0%) — 취약 광종 특화로 코발트 물량 **17% 추가 개선**
     (62→51%), 니켈 단가 4% 추가 개선(38.6→36.9%)
   - 수급위기 진단의 보조 조기경보(전환 감지) 정확도 지표 **0.83→0.89**,
     오경보율 **0.21→0.15**
   - 지정학 급증확률의 희토류 상시경보 왜곡 해소(급증확률 0.52→0.12 정상화),
     코발트 급증확률 정확도 개선
3. **재검정 체계 확립**: 향후 신규 데이터(발주처 제공분 포함)가 들어오면
   표준 재검정 절차가 자동으로 수행되도록 검정 하네스를 구축했습니다 —
   추가 데이터 제공 시 **수일 내 효과 검증·반영**이 가능합니다.

## 3. 모델 개선 결과 (전 항목 통계 검증 통과분만 반영)

검증 원칙: 모든 개선은 과거 데이터 워크포워드 백테스트에서 ① 부트스트랩
신뢰구간이 0을 상회(우연 아님) ② 설정 변형(이웃·시드)에도 유지 ③ 데이터 재발행
후에도 유지 — 3중 검증을 통과한 것만 운영 반영했습니다. 기준 미달 개선은
"보류"로 정직하게 분류해 관리합니다.

### 3.1 12개월 수입물량·수입액 예측 (산출물 ②)

| 지표 | 개선 전 | 개선 후 | 개선 내용 |
|---|---|---|---|
| 수입물량 예측오차(WAPE, 18개 기점 평균) | 29.3% | **26.3%** | 모델 교체(극단 랜덤화 트리)+주간 지정학지수의 시간가중 반영+최근 체제 가중 |
| 수입단가 예측오차 | 20.0% | **18.0%** | 가격·환율의 월말 수준/추세 반영(혼합주기 기법) |
| 코발트 물량(최난이도 광종) | 62% | **51%** | 광종 특화 2단계: 정칙화 선형 교체 후 최근 관측 가중 추가 |
| 니켈 단가(취약 세부항목) | 38.6% | **36.9%** | 광종 특화(최근 관측 가중) — 5광종×물량/단가 10개 세부항목 전수 점검에서 발굴 |

추가로 5광종×물량/단가의 세부항목별 성능을 전수 실측해 취약 항목 2건(코발트
물량·니켈 단가)을 식별하고 각각 광종 특화 개선을 적용했습니다. 두 건 모두
동일한 3중 검증(통계 유의성·설정 강건성)을 통과한 것만 반영했습니다.

부수 확인: 신규 수집한 무역·거시 29종을 예측 입력으로 전수 검정한 결과 유의한
추가 개선은 없었습니다 — 월간 수입은 자기 이력이 지배하는 구조로, 예측 개선은
데이터 추가보다 모델 기법에서 나왔음을 4차례 반복 확인했습니다.

### 3.2 수급위기 진단 — 보조 조기경보 (산출물 ①의 병기 신호)

운영 4단계 경보(법정 단계 산출)는 안정성 우선으로 **변경 없음**(정확도 지표
QWK 0.97 수준 유지). 그와 별개로, 등급 "전환"을 조기 감지하는 보조 신호를
신설·강화해 별도 발행합니다(경보 등급을 바꾸지 않는 참고 신호).

| 지표 | 주말 개선 전 | 현재(v2) |
|---|---|---|
| 전환감지 정확도(QWK) | 0.83 | **0.89** |
| 오경보율 | 21% | **15%** |
| 전환 적중률 | 23% | **27%** |

개선 요인: ① 서로 다른 정보 원천(모델 확률·원시 이벤트 누적·거시 사이클)의
앙상블 ② 이번 확충에서 채택된 신규 지표 2종 — **OECD 한국 경기선행지수**(수요
사이클 축)와 **아르헨티나 리튬 수출**(리튬 최초의 유의 공급 신호, 조건부).

### 3.3 지정학 위기지수 (산출물 ③)

- **희토류 상시경보 왜곡 해소**: 급증 판정 기준이 과거에 고정되어 희토류가
  2024년 이후 "상시 급증"(확률 0.52)으로 표시되던 문제를 적응형 기준(최근 52주
  분포)으로 해소 — 현재 0.12로 정상화. 기존 값도 병기 발행(비파괴).
- **코발트 급증확률 정확도 개선**: 예측오차(Brier) 0.206→0.175 — 종전에 단순
  기준선에도 못 미치던 유일한 약점 광종을 해소.
- 실물 타당성 검증: 동(銅) 지수의 상위 10% 주가 칠레 Escondida 파업(2017)·코로나
  봉쇄(2020) 등 실제 공급차질과 일치함을 통계적으로 확인(동시 탐지 지표로서
  타당— 물리 시계열 선행 예측력은 없음을 정직하게 명기).
- 리튬 급증확률은 단순 기준선과의 미세 격차(0.005)가 통계적으로 무의미함을
  검증으로 확정(6개 개선 변형 전수 검정 — 모델 측 개선 여지 없음). 실질 개선은
  리튬 선행 신호 데이터 확충(4장 요청 항목의 EV·배터리 장기 데이터 등)과
  연동됩니다.

### 3.4 모니터링 대시보드 (산출물 ④)

보조 조기경보(방향·확률)와 적응형 급증확률을 대시보드에 신설 노출했으며,
재생성이 스크립트화되어 최신 DB 상태로 상시 갱신 가능합니다.
