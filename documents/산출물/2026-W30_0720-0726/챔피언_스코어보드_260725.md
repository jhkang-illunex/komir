# 모델 챔피언 스코어보드 — 기존 vs 신생 (2026-07-25 확정)

주말 탐색(스코어카드 v1.12~v1.16, WORKLOG 최신⑯~㉒)의 최종 정리. 모든 수치는
동일 백테스트 프레임에서 직접 측정(진단 = Δ분류 워크포워드 3폴드·패널 종점
2026-06-08 발주처 컷 / 예측 = 직접 다지평 18오리진×h1..12 WAPE / 지수 확률화 =
train ≤2023 · test 2024+ Brier). "현 발행본" = 2026-07-25 토 06:30 GKG cron
재발행 이후 상태. 유의성 = 부트스트랩, 채택 기준 = CI 하한>0 + 이웃설정 강건 +
**발행본 변동(±0.01~0.03 QWK) 초과**(v1.16에서 추가된 기준).

## 축별 상세

### 1. 진단 Δ 보조 조기경보
- 신챔피언 외 대등 구성(전부 P≥0.993): Bagging25+**동일피처**(0.8492 — 피처 불변
  순수 랩핑이라 재발행 비교 완전공정), Bagging50+병행(FAR **0.1484** 최저),
  Bagging25+gsev대체(0.8658). 용도별 선택 가능.
- 기각·강등: gsev_z13 단독대체(아침 P=0.997 → 재발행 후 P=0.636 — v1.15에서
  강등), AdaBoost 랩핑(전환 반토막), 트리·커널·신경망 단독(다수클래스 붕괴),
  발행본-독립 구성(지수피처 제거 — P=0.000 유의 악화).
- 전환적중 최고가 필요하면: +gsev_hl2 고재현율 지점(0.42, QWK 희생) 별도 보존.

### 2. 예측(12개월 수입물량·수입액)
- 귀속 분해: ton은 모델 효과(HGB→XT)가 주도+지수 MIDAS 가산, unit은 모델+피처
  효과 가산적(XT+BASE 0.1880 → XT+wpx/wfx 0.1799).
- 대등 구성: 모델평균 HGB+RF+XT(ton 0.2664·unit 0.1820/6오리진), RF 단독.
  SVR·kNN·MLP·PLS 전부 미달. 참고: 계절나이브 ton 0.270(6오리진) — XT+MIDAS지수
  (0.2659/6오리진)가 **나이브도 역전**(이 오리진 표본 최초).
- 강등: HGB+MIDAS지수(재발행 후 P=0.732 — XT 결합으로 대체됨).

### 3. 지수 확률화
- CO만 광종별 채택(풀링 병행은 0.1244→0.1194 전 설정 일관이나 P=0.967 보류).
- 도전 실패 계열: NB2 동역학 피처확장·스플라인 NB2·단조제약 HGB(REE 체제전환
  붕괴 0.35)·GBM·로지스틱·NB2+로지스틱 앙상블(P=0.901)·x_geo 대체(REE 붕괴).

### 추기 3(2026-07-26) — LI 지수 "잔여 약점" 검정: 채택 0건, 약점 실재 부정

15셀 중 마지막 △셀(LI Brier 0.1176 vs 상수 0.1130)을 6변형으로 검정
