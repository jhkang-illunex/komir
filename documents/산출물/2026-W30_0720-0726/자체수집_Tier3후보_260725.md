# 자체 수집 Tier3 후보 (2026-07-25, 전 항목 접근성 실측)

사용자 요청: "지금 수집된 데이터 이외에 영향을 줄 가능성이 있는 데이터의 수집
방안·가능성 검토". 모든 "실측✓"는 오늘 실제 API/URL 호출로 데이터 존재를 확인한
것. 우선순위 논리는 기존 3원칙(물리량 우선·히스토리 2016+·광종별 재검정) +
이번 주말 확립된 추가 원칙 2개: ④검정 채택은 새 정보 축일 때만 가능성 높음
("보팅은 원천이 다를 때만"과 동전의 양면), ⑤예측모델은 lag 지배라 외생 기대
낮음 — 주 타깃은 진단 광종축·지정학 연계·모니터링 서사.

현재 격차(후보 선정 기준, 15셀 매트릭스 기준): LI·CO·REE 진단 전환 표본 부족
(데이터가 아닌 시간 문제)이므로, 데이터로 접근 가능한 격차는 **LI 공급축의 남미
반쪽 부재**(현재 호주 광석축만), **NI 광석 대체공급축 부재**(인니 단일),
**REE 비중국 공급축 부재**(중국 수출은 2024-12 컷), NI unit 최악 셀(0.384 —
단 이는 신규 수집이 아니라 기보유 관세청 HS 세분화 가공 사안).

## 보류/불가(정직 기록)

- **조달청 비축물자 재고**: 공공데이터포털 검색·웹검색에서 재고 API 미확인 —
  비축량은 안보 사안으로 통계 비공개 추정. **발주처 경유 확보가 자연스러운 항목**
  (KOMIS-조달청 연계) → 발주처 안건 3호 후보. 나라장터 방출입찰 공고로 간접
  추적은 가능하나 가공 비용 대비 신호 희박.
- 페루 CU 수출: 2024-12는 존재하나 2025-12·2026 전부 0행 — **보고 지연 12개월+**
  → 후순위(칠레축이 이미 있음).
- DRC·잠비아 CO 수출: Comtrade 미보고(0행 실측) — 기존 중국측 수입(2024-12 컷)이
  유일 경로 유지.
- 호주 REE 수출(2846): 월 2t 무의미량(정광은 말레이시아 Lynas 경유 — #4로 대체).
- USGS 니켈 MIS: 월보 부재 실측(코발트·구리만 존재).
- 기왕 불가 확정 유지: CME/COMEX(403)·lme.com(WAF)·CO LME 주간(유료)·FRED(차단)·
  NBS(403)·SMM/Earth-i/EV장기(유료)·REE쿼터(비공개).

## 기대 영향 정직 평가

- **가장 유망**: #1+#2(LI 남미축)와 #3(NI 대체공급) — 진단 Δ프레임의 광종축
  후보이자, "원천이 다른" 신호라 기존 채택축(호주 LI·인니 NI)과 보팅/병행 여지.
  #4(말레이 REE)는 geo 이벤트(중국 수출통제 서사)와 물리 흐름을 잇는 두 번째
  다리(첫째는 미얀마→중국) + REE 최신성 공백 보완.
- 예측모델 투입은 기대 낮음(외생 2회 전패·lag 지배) — 수집 후에도 진단·지수
  연계 축으로 검정하는 것이 맞음.
- 수집 즉시 채택이 아니라 동일 백테스트 검정 필수(원칙). 부분 커버리지 교란
  플래그: 전부 2016~ 히스토리 확보 가능 여부를 수집 시 실측할 것(이번 프로브는
  2024-12 단면).
