## 3. 불가 판정의 두 가지 성격 — "접속 차단" vs "헤드리스로도 안 뚫림"

"불가"로 표시한 항목이 전부 같은 이유는 아니다. 이번 조사에서 실제로 구분되는
두 유형이 나왔고, 대응(추가 투자 여지 있음/없음)도 다르다.

### 3-1. 필리핀 MGB — 단순 접속 차단(WAF 403), 헤드리스 시도 자체를 안 함

광물지질청(MGB) 본청 도메인은 **일반 HTTP 요청 단계에서부터 전역 403**이다
(WAF 기반 데이터센터 IP 차단으로 추정 — 검색엔진 색인은 정상 노출되는 걸
보면 사이트 자체는 살아있음). 이건 GACC처럼 "브라우저가 아니면 통과 못 하는
JS 챌린지"가 아니라 **요청 자체가 거부되는 접속 차단**이라, 헤드리스 브라우저
우회를 시도조차 하지 않았다(시도 대상 자체가 아님 — 우회할 JS 챌린지가 없다).
- 지방청(region1·region3 등 13곳)은 **접속은 정상**이나, 확인한 214개 링크
  전부 PDF였고(Excel·CSV 0개) 전국 합계를 내려면 13곳을 전부 병합해야 해
  비용 대비 효율이 낮아 착수하지 않았다 — 이건 접속 문제가 아니라 **포맷·
  집계 비용 문제**다.
- 최종 대응: 관세청(BOC) 원자료를 배포하는 **통계청 PSA로 대체**(무키·완전
  자동, `PH_NI_EXPORT_VAL/WGT_PSA`) — MGB 원본 재시도는 필요 없다(대체
  경로가 이미 같은 정보를 더 좋은 형태로 제공).

### 3-2. 중국 GACC 상세 — 헤드리스로 실제 시도했으나 5종 전부 실패(참고)

중국 세관 상세통계(`stats.customs.gov.cn`)는 순수 HTTP 요청을 412+JSL(가속락)
JS 쿠키 챌린지로 차단. headless 브라우저 우회를 5단계로 실제 시도(기본
Playwright·명시적 재로드·개별 지문패치·`playwright-stealth` 표준
라이브러리·HTTPS 우회)했으나 **전부 실패**(HTTP 경로는 400, HTTPS 경로는
다른 CDN을 거쳐 504) — 챌린지 자체가 VM 바이트코드로 난독화된 상용
봇탐지 코드라 역공학도 비현실적. **"취약"에서 "불가"로 판정 하향, 이 방향
추가 투자는 재시도 금지**([[gacc-headless-failure-260729]] 메모리 참고).
니켈·코발트·리튬 3광종에 한해 상용 벤더 구독만이 유일한 실행 경로.
