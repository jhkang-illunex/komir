   - `REG03` 최근 니켈 가격
   - `REG04` 니켈 연도별 평균 가격
   - `REG06` 니켈·텅스텐 가격 비교
   - 모두 니켈 단일 가격 질의(`REG02`)는 정상인데 복합/표현 변형에서
     `unsupported_commodity`로 종료됐다. 데이터 부재가 아닌 slot/라우팅 회귀다.

2. **기본 기간·대상 결정 미구현/미결정 (5건)**

   - `MP08` 이번달 희소금속 월간동향 광종 가격: `slot_unresolved`
   - `CN02` 이번 주 가격 변동 상위 광종과 뉴스: `slot_unresolved`
   - `CN03` 광물종합지수 구성 광종 중 상승 전망: `slot_unresolved`
   - `CN04` 수입 의존도 높은 광종 가격 전망: `slot_unresolved`
   - 질문이 지시한 이번 주/이번 달/최근 기준을 Action slot의 기본값으로
     확정하거나, 필요한 원천이 없을 때 `source_unavailable`로 일관되게 닫아야 한다.

3. **복합 응답의 한쪽 구성요소 누락 (8건 중 원천 확인 필요 포함)**

     forecast action이 실제 근거를 내지 못했다.
   - 가격+월간동향: `MP09` — 가격만 응답, 월간 문서는 미확보.
   - 용도+수입국: `GM05` — 수입국만 응답, 망간 용도 원천 미확보.
   - 기준 이상 가격상승+뉴스: `CN01` — 최근 관측에서 5% 이상 상승일을 찾지 못함.

     `점유율`이 아니라 `%`여서 자동 키워드 검사가 부분으로 분류했으므로 기능 실패로 보지 않는다.

## 원천 보완 후 재점검 대상

다음 19건은 `source_unavailable`로 종료되어 현재 값·요약·기사를 만들지 않았다.
광물 특성/광석(`MI02`~`MI04`), 월간동향(`DOC01`~`DOC03`, `GM06`, `GM09`),

(`CN06`~`CN09`, `REG07`)이 해당한다. `REG01` 리튬 주요 수출국은
`no_data_for_period`로 종료되어 데이터 보완 대상으로 분류한다.
