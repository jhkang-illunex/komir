# 챗봇 public 24문항 질의·판정·사유

| 질의문항 | 답변 판정 | 사유 |
| --- | --- | --- |
| **Q01** 최근 1년간 니켈 가격 추이를 보여줘. 기준일, 가격 단위, 출처도 알려줘. | 부분 | 기간 수정 후 요청 범위의 관측 252행을 반환하지만 가격 단위를 설명하지 못하고 선택한 실가격 시리즈에 잘못된 더미 경고가 붙는다. |
| **Q02** 코발트 광물종합지표의 최근 12개월 변화를 차트로 보여주고 주요 변화를 설명해줘. | 통과(정상 기권) | 광물종합지수는 코발트별 지표가 아니므로 차트를 만들 수 없다는 범위 오류를 정확히 안내했다. |
| **Q03** 한국의 리튬 수입 상위 5개국과 국가별 비중을 차트로 보여줘. 대상 기간과 금액 기준인지 중량 기준인지 알려줘. | 통과(시연) | 국가별 금액 비중·기간·차트를 제공했다. 원천이 개발용 더미여서 실제 한국 수입 순위는 아니다. |
| **Q04** 희토류 생산량과 매장량 상위 5개국을 각각 차트로 보여줘. 통계연도와 단위도 알려줘. | 통과(시연) | 두 순위와 차트·연도·단위를 제공했다. 값은 개발용 더미다. |
| **Q05** 구리, 니켈, 코발트의 최근 1년 가격 추이를 비교해줘. 가격 단위가 다르면 비교 방법을 설명해줘. | 부분 | 공통 관측일 비교는 했지만 실제 가격 관측은 약 2개월뿐이고 구리·코발트는 더미다. |
| **Q06** 리튬 가격의 최근 3개월, 6개월, 1년 변화를 비교하고 가격 기준과 등락률 계산 기준일을 알려줘. | 부분 | 세 기간의 실제 관측 범위가 모두 약 2개월로 같아 3·6·12개월 비교를 충족하지 못한다. 가격도 더미다. |
| **Q07** 텅스텐 가격의 최근 1년 추이를 차트로 보여줘. 어떤 제품·규격의 가격인지 알려줘. | 부분 | 일부 가격·차트만 반환했고 최근 1년 전체 관측과 제품·규격 설명이 없다. |
| **Q10** 리튬의 가격 하락과 수급위기 위험은 어떤 관계가 있어? 현재 데이터에 근거해 설명해줘. | 실패 | 과거 시장 문서와 더미 가격을 나열했을 뿐 현재 위기 위험과 가격 하락의 관계를 검증하지 못했다. |
| **Q11** 한국의 코발트 수입액과 수입중량의 최근 12개월 추이를 각각 차트로 보여줘. | 부분 | 두 월별 합계·차트는 있으나 관측은 약 4개월의 더미라 12개월 실측 추이가 아니다. |
| **Q12** 한국의 니켈 수입국 집중도를 HHI로 계산해줘. 대상 기간, 계산식, 사용한 국가별 비중을 알려줘. | 통과(시연) | 전체 10개국 비중으로 HHI를 계산하고 기간·산식을 제시했다. 통관 원천은 더미다. |
| **Q13** 구리의 세계 생산국 비중과 한국의 수입국 비중을 비교하고 공급망 취약점을 설명해줘. | 부분 | 두 모집단의 비중·기간은 구분했지만 한국 수입 표본이 더미여서 실제 공급망 취약점을 판단할 수 없다. |
| **Q14** HS코드 2603000000의 품목명과 한국 수입 현황을 알려줘. 광종 전체 수치와 구분해줘. | 통과(실자료) | 구리광·정광 품목과 해당 HS만의 수입액·중량을 제시했고 원천 SQL 합계와 일치했다. |
| **Q15** 희토류와 네오디뮴은 같은 범위의 데이터야? 가격과 생산통계를 비교할 때 주의점을 알려줘. | 실패 | 두 통계의 범위와 비교 주의점을 설명하지 않고 질문이 모호하다고 기권했다. |
| **Q17** 리튬 비축 현황과 목표 대비 부족량, 비축일수를 알려줘. 자료가 없으면 필요한 입력값과 계산식을 설명해줘. | 실패 | 비축 실수치 부재만 말하고 질문이 허용한 입력값·부족량·비축일수 계산식을 제공하지 않았다. |
| **Q20** 전기차 수요가 둔화되면 리튬·니켈·코발트에 어떤 영향이 있을까? 데이터로 확인된 내용과 추론을 구분해줘. | 실패 | 수요 비중과 과거 동향만 제시하고 세 광종별 조건부 영향과 근거·추론의 구분을 답하지 못했다. |
| **Q21** 핵심광물 공급망 다변화에서 재활용이 할 수 있는 역할과 한계를 설명해줘. | 답변 보류(출처 미확인) | 최종 출처 확인 정책 적용 후 확인 가능한 직접 근거가 없어 `확인 가능한 출처가 없어 내용을 확인할 수 없습니다.`로 기권했다. 무출처 내부 지식 설명은 표시하지 않는다. |
| **Q22** HHI와 수입의존도, 가격변동성의 차이를 비전문가도 이해할 수 있게 예시로 설명해줘. | 답변 보류(출처 미확인) | 최종 출처 확인 정책 적용 후 세 개념의 차이를 직접 뒷받침하는 출처가 확인되지 않아 같은 고정 문구로 기권했다. 인용·출처·가상 예시는 표시하지 않는다. |
| **Q23** 니켈 가격 추이 좀 보여줘. | 부분 | 기간 미지정 조회는 수정 후 환경변수 상한인 60행을 반환한다. 다만 실가격 시리즈에 잘못된 더미 경고가 붙고 단위 설명이 없다. |
| **Q24** 그럼 같은 기간 코발트와 비교해줘. 기준 기간과 단위를 다시 표시해줘. | 부분 | 같은 기간의 변동률 비교는 했지만 단위를 사람이 이해할 명칭 대신 코드로 표시했고 코발트 가격은 더미다. |
| **Q25** 그중 가장 크게 하락한 광물과 하락률을 알려줘. 계산에 쓴 시작값과 끝값도 보여줘. | 통과(시연) | 앞선 비교의 시작값·끝값으로 코발트 하락률을 계산했다. 코발트 값은 더미다. |
| **Q26** 2030년 리튬 실제 월별 가격을 차트로 보여줘. 아직 없는 실측 자료라면 없다고 알려줘. | 통과(정상 기권) | 미래의 실제 월별 가격은 아직 없다고 안내했다. |
| **Q27** 언옵테이늄의 한국 수입국 비중과 현재 위기점수를 알려줘. | 통과(정상 기권) | 등록되지 않은 광종의 수입 비중·위기점수를 만들어내지 않았다. |
| **Q29** 2026년 1월부터 12월까지 리튬 수입액을 2025년 연간 수입액과 비교해줘. 아직 없는 월과 비교 가능한 기간을 구분해줘. | 통과(시연) | 월별·연간·동일 기간과 미집계·미래 월을 구분했다. 통관 값은 더미다. |
| **Q30** 오늘 서울 날씨와 점심 메뉴를 추천해줘. | 통과(정상 기권) | 광물 챗봇의 범위 밖 질문으로 안내했다. |
