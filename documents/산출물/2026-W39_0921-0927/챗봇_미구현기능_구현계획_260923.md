# 챗봇 수정 예정 항목 구현 현황

작성일: 2026-09-23

## 상태 표기

- **완료**: 코드·단위 검증까지 끝난 항목
- **진행 중**: 코드가 있으나 데이터 재처리 또는 실제 수락 검증이 남은 항목
- **미착수**: 아직 구현을 시작하지 않은 항목

## 현재 구현 상태

- **완료**: RDB·pgvector·PageIndex 조회, OKF 원문 확인, HHI, 페이지 안내, 실패 문구 리소스화.
- **완료**: `trade.indicator`, `komis_trade_indicator`, `trade_metric`·기준국·상대국 슬롯, 무역지표 전용 HITL.
- **완료**: TSI·수출입증감률·특정국 의존도 계산. 전년 금액이 0이면 증감률은 계산하지 않는다.
- **제약 확정**: RCA·TII는 세계 전체 분모 원천이 검증되기 전까지 수치를 반환하지 않는다. 현재 `KO_UN_CMMRC`는 9개 HS의 부분 표본이다.
- **진행 중**: 조달청 PDF OCR 재처리는 868건 OKF 생성까지 완료됐다. PageIndex·pgvector 재색인과 PDF·HWP·Excel 질의 수락 검증이 남았다.

## 구현 범위

1. **완료**: `trade.indicator` Action과 `komis_trade_indicator` MCP 도구를 추가했다.
2. **완료**: 지표 선택은 새 `trade_metric` 슬롯으로 분리했다. 기존 `metric`의 의미는 유지한다.
3. **완료**: 기준국(`reporter_country`)과 상대국(`partner_country`)을 분리했다.
4. **완료**: HITL은 새 `trade.indicator`의 필수 슬롯이 누락됐을 때만 동작한다.
5. **진행 중**: RCA·TII는 HS 코드, 국가·세계 전체 분모, 기간·통화·HS 분류가 검증된 뒤에만 계산한다.

## 지표별 필수 조건

| 지표 | 필수 입력 | 계산 조건 |
|---|---|---|
| TSI | 품목, 기준국, 기간 | 동일 품목·기간의 수출액·수입액, 분모 0 제외 |
| RCA | HS 품목, 기준국, 기간 | 국가·세계의 품목/전체 수출액 모두 필요 |
| TII | 기준국, 상대국, 기간 | 기준국의 상대국 수출·전체 수출, 상대국의 세계 수입·전체 수입 필요 |
| 수출입증감률 | 품목, 기준국, 수출입 방향, 대상 연도 | 전년 동일 기간 값 필요, 전년 0은 계산 불가 |
| 특정국 의존도 | 품목, 기준국, 상대국, 수출입 방향, 기간 | 특정국 금액/전체 금액, 상위 N개 합계는 분모로 사용하지 않음 |

## 별도 결정·검증 항목

- 현호님과 `evidence_status` 및 `no_evidence`의 외부 계약을 합의한다.
- **완료**: 차트·표의 기간 표시는 데이터 블록에만 적용한다: 3개월 이하 일간, 3개월 초과~1년 미만 주간, 1~3년 월간, 3년 초과 연간. 원천 빈도가 낮으면 원천 빈도를 우선한다.
- **완료**: 표·차트에서 순번·거래/레코드 건수·내부 일련번호·중복 블록을 제거하고, 공통 단위·기준일·출처는 블록 메타로 이동한다.
- **완료(1차)**: `menu_data_catelog.yml`에 report_gen 3개 주메뉴·11개 페이지의 메뉴·원천 테이블·표시 출처를 정리하고, 메뉴 매핑이 있는 RDB 인용·표·차트에 표시하도록 연결했다. PDF·HWP·Excel 보고서는 실제 문서명을 유지한다. 추가 메뉴는 YAML에 등록해 같은 경로로 확장한다.

## 수락 기준

- 기존 Q01~Q30, 문서 조회, HHI, 페이지 안내가 회귀 없이 통과한다.
- 무역지표는 공식·분자·분모·기간·메뉴/원천 출처를 함께 반환한다.
- HITL은 무역지표의 누락 슬롯에서만 `slot_required`를 반환하고, 완전한 입력은 추가 질문 없이 조회한다.
- OCR 재색인 완료 후 대표 PDF·HWP·Excel 질의가 새 OKF·PageIndex·pgvector 근거를 반환한다.
