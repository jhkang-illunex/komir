## 잔여 수정 사항 점검

현재 커밋 기준으로 배포 서버의 기능 결함으로 확정된 잔여 수정 사항은 없다.

- 페이지 typed action과 일반 페이지 추천은 공통 안내 형식으로 통일됐다.
- 무역 후속 질의가 완료된 이전 답변을 새 의도에 재사용하지 않는다.
- 가격 주장·무역 지표의 수치 검증과 출처 표시는 통과했다.
- pgvector 5개 통합 검사는 모두 PASS했다.

운영 인프라 조건으로 남은 항목은 두 가지다. PostgreSQL/pgvector 연결이 끊긴
환경에서는 해당 통합 검사를 `BLOCKED_ENV`로 기록하고 연결 복구 후 재검증해야
하며, RCA/TII 세계 분모 provider는 실제 원천이 연결될 때까지 의도적으로
`source_unavailable`을 반환한다. 둘 다 현재 코드의 미수정 기능 결함으로
분류하지 않는다.
