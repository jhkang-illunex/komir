# Public 챗봇 개념 질의의 출처 확인 정책

작성일: 2026-09-21. 대상: Q21·Q22처럼 정의·차이·일반 원리를 묻는 질문.

## 최종 정책

개념 질의도 먼저 OKF·PageIndex 등의 근거를 조회한다. 확인 가능한 출처가 없거나 검색 결과가 질문을 직접 뒷받침하지 못하면 `확인 가능한 출처가 없어 내용을 확인할 수 없습니다.`만 반환한다. `citations=[]`, `abstain_reason=source_unavailable`로 종료하며 모델 내부 지식으로 만든 설명이나 출처 없는 데이터는 표시하지 않는다. 출처가 있을 때도 생성 문장을 화면에 내보내기 전에 인용 번호를 검사하고, 각 문장의 내용이 해당 인용 근거에 의해 뒷받침되는지 검증한다. 검증 실패도 같은 방식으로 기권한다.

근거 데이터의 인용 번호와 답변 말미 출처 목록은 번호별로 1:1 표시한다. 동일한 문서·절을 가리키는 서로 다른 근거 번호도 합치지 않는다. 이전 Q20 응답에서는 인용 `[1]`, `[3]`이 같은 문서 정보를 가져 출처 목록이 한 줄만 표시되던 사례가 있었다. 이 경우 이제 `[1]`, `[3]`을 각각 표시한다.

## 검증

테스트 컨테이너 `/pubchat` 실요청에서 Q21·Q22·신규 HHI 개념 질문은 모두 위 고정 문구로 기권했다. 세 응답 모두 표·차트·인용 0건이며, `done.citations=[]`였다. 실제 집계 질문 Q12는 PostgreSQL 집계 결과와 출처 1건, Q30은 기존 범위 밖 거절을 유지했다. 실응답과 SSE는 `data_archive/validation_runs/rag_chat_internal_knowledge_260921/source_first/`에 보존했다. 관련 회귀 테스트 22개가 통과했고, Q20과 같은 중복 문서 인용 번호의 출처 목록 보존도 단위 테스트로 확인했다.

테스트 이미지 `komir-rag-chat:260921-sourcefirst-r1`을 빌드해 `komir-rag-chat-test`에 적용했다. 이미지 안의 `chatbot.py`와 작업공간 파일 SHA-256은 `6e3ae85e0b894d756cf3e3271b24a78f945d1763e6526f024e9c17bd77b17ea2`로 일치한다. 운영 배포·커밋·push는 수행하지 않았다.

이전 무출처 Gemma 설명 경로와 그 시험 결과는 사용자 정책 변경으로 **폐기된 실험**이다. 해당 SSE는 추적을 위해 남겼으며 최종 판정의 근거로 사용하지 않는다. LLM의 근거 적합성 검사는 문장별 자동 검증이므로 의미적 정합성을 절대적으로 보증하지는 않는다.
