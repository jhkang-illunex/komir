# 30문항 대응 RAG Kit 구조 감사

기준: 2026-09-21 작업공간 코드와 당일 public 30문항 검수 기록. 읽기 전용 감사이며, 이 문서의 결론은 30개 원문 외 표현까지 재실행해 검증했다는 뜻이 아니다.

## 결론

주먹구구식 분기가 실제로 있다. 특히 질문에 필요한 **데이터 종류와 출처의 사용 가능 여부**를 먼저 확정하지 않고, 라우팅 결과에 검색 도구를 추가한 뒤 근접 문서를 대안 근거로 제안하는 구조가 문제다. 한편 가격·통관·생산 등의 결정적 SQL 집계 자체는 재사용 가능한 기능이다. 모든 분기가 임시방편인 것은 아니다.

## 확인된 문제

| 우선순위 | 코드 근거 | 영향 |
|---|---|---|
| 높음 | `inhouse/rag_core/ragkit/chatbot_graph.py:140`은 비활성 진단·수입예측·지정학 산출물 질의도 dense/PageIndex로 검색하도록 지시한다. `inhouse/rag_core/ragkit/chatbot.py:174`의 기권은 특정 ‘현재 수급위기’ 단어 조합에만 적용된다. | Q08과 표현이 조금 다른 진단 질문, 예측·지정학 질문은 무관한 문서를 관련 근거로 표시할 수 있다. 새 DB 연계 전에는 이 산출물을 다른 자료로 대체하지 않는다는 최신 결정과 충돌한다. |
| 높음 | `inhouse/rag_core/ragkit/chatbot_graph.py:885`의 가격 비교 감지 조건에 평가 문항의 `300%`가 직접 들어가고, 광종 5개를 이름으로 열거한다. | 30문항에 포함된 표현은 통과해도 다른 수치·광종·동의어의 경로 일관성이 보장되지 않는다. |
| 중간 | `inhouse/rag_core/ragkit/chatbot_graph.py:1643`은 구조화 근거 1건이 있으면 문서 근거를 모두 제거한다. `:1686` 근접 제안도 구조화 근거가 있으면 나머지를 버리고, 없으면 광종명 포함 여부만으로 문서를 남긴다. | 복합 질문의 다른 정보요구를 뒷받침하는 근거가 사라지거나, 같은 광종만 언급한 무관 문서가 남을 수 있다. |

당일 30문항 독립 검수는 **통과 13·부분 7·실패 10**이었다. 이 수치는 해당 시점의 단회 실요청 결과이며, 이후 Q21·Q22 출처 정책과 Q08 임시 차단의 변경분을 합쳐 다시 전수평가한 수치는 아니다. 문항별 근거는 `챗봇_public_잔여작업_검수결과_260921.md`에 있다.

## 정리 방향

1. 질문을 문구별로 차단하기 전에 요구 데이터를 `가격·통관·생산·매장량·진단·예측·지정학 지수·관련 기사·문서 개념`처럼 분류하고, 각 종류의 **공식 데이터 원천·연결 상태·기준시점·필수 컬럼**을 명시한다. 신규 진단·예측·지정학 DB의 구조는 미정이므로 지금 테이블명을 가정하지 않는다.
2. 공식 원천이 미연결인 결과형 질문은 검색 전에 자료 부족으로 종료한다. 일반 문서 검색은 사용자가 문서 내용·개념 자체를 물을 때만 사용하고, 미연동 지표의 수치나 최신 기사를 대체하지 않는다.
3. 복합 질문은 정보요구별로 근거를 유지하고 각 요구의 충족 여부를 확인한다. 하나의 구조화 근거가 있다는 이유로 다른 요구의 문서 근거를 일괄 삭제하지 않는다.
4. 평가 30문항은 회귀 집합으로 유지하되 숫자·광종·어순을 바꾼 변형 질의도 검사한다. 특정 문항의 문자열을 새 분기의 조건으로 추가하는 방식은 중단한다.

이번 감사에서는 코드·서비스를 변경하지 않았다.
