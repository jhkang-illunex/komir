# 해외 국가 관세·정책 데이터 수집 확장 — 조사·반영 결과 (2026-07-28)

발주처 지정 수집 대상(tier1 3개국·tier2 6개국, 국가×광종×기관)에 대해 기관별
공개 데이터 경로를 전수 조사(웹 조사 3건 + 본 서버 실호출 재검증)하고,
**무키·무인 수집이 가능한 소스는 당일 수집기 구현·백필까지 완료**했다.
API 키 발급·유료 구독 등 별도 절차가 필요한 소스는 §4에, 기술적 불가와
대안은 §5에 정리한다. 모든 판정은 실제 HTTP 호출 결과 기준(문서 재인용 없음).

(채택 기준 CI 하한>0 미달). 기존 보류 6건에 합류, **전환 표본 축적 시 재검**
(ph_psa는 동일 원천 Comtrade ni_ph P=0.687보다 뚜렷이 강해 축적 후 대체 1순위).
**예측 exog**: 신규 8건 전부 기각(ΔWAPE<0.005 — "예측은 lag 지배" 5번째 확인).
채택 반영 0건 = 챔피언 구성 불변. 상세: `outputs/model_opt/r10_retune_report.md`
(직전 주말판은 `r10_retune_report_260725_weekend.md`로 보존). 배경 맥락:

- **PH_NI(PSA)**: Comtrade 필리핀 보고(PH_NI, P=0.687 방향긍정 보류)와 원천이
  같은 신고 데이터 — "새 정보 축" 요건상 대체재이지 추가축이 아님. 단 PSA가
  래그·결측에서 우위면 계열 교체 후보.
- **PE_CU(BCRP)**: 페루는 Comtrade 래그 12개월+로 기왕 기각된 국가 — BCRP 경유
  래그 ~2개월은 **신규 공급축**(세계 2위 동 생산국)으로 검정 가치 높음.
- **CN_CU/REE(GACC)**: 중국계 5흐름 2024-12 컷(②-a 보류 병목)의 최신치 대체 —
  cn_cu·cn_ni 보류 해소 재검정 트리거에 직접 연결(NI는 미커버라 cn_ni는 여전히
  유료 경로 대기).
- **AU(ABS)**: 호주 니켈광·동광 수출 — 공급국축. LI(스포듀민)는 SITC 한계로
  이 경로 불가, REQ(§6) 또는 발주처 유료 채널 필요.
- **정책 공고 2종**: 시계열 피처보다는 지정학 지수(geo_event)의 검증·보강 축과
  모니터링 서사용. geo_event가 뉴스 기반으로 이미 커버하는 이벤트의 **정부 정본
  확인 채널**.

## 6. 후속 구현 후보(반자동·2단계 수집기) — 우선순위순
