## 1. 시스템 개요

5광종(CU·NI·CO·LI·REE — 희토류 대표원소는 네오디뮴 확정)에 대해 3개 모델 모듈을
운영한다: ① 지정학 위기지수·급증확률(비정형 파이프라인) ② 수급위기 진단 4단계
경보 + 보조 조기경보(정형) ③ 12개월 수입물량·수입단가 예측(정형). 전 구간이
실데이터로 주간/월간 cron 체인에서 무인 가동되며, 산출은 운영 DB의 `out_*`
테이블과 모니터링 대시보드로 발행된다.

```
[비정형] GDELT GKG ─파싱→ LLM재검증 ─관련성정제→ geo_event(29.6만) ─집계→ geo_index ─확률화→ geo_prob
                                                            │                    │
[정형] 관세청·KOMIS·재고·거시·무역흐름 ─표준화 적재→ fact_*/raw_* ─피처화─┴─→ ②진단(레벨+Δ조기경보)
                                                                         └─→ ③예측(ton/unit, h1..12)
```

## 3. 전처리 과정

### 3.1 비정형(geo) — GKG → geo_event

1. **1차 규칙 파싱**(`geo/gkg_parse.py`): GDELT GKG 벌크에서 광종 후보 추출.
   CU·NI는 GDELT 전용 테마코드(WB_2934/2935) 정확 매칭, CO·LI·REE는 URL·개체명
   키워드 매칭(전용 코드 부재 — 동음이의어 혼입 경로로 한계 명기).
2. **LLM 재검증**(`geo/gkg_verify.py`): 로컬 vLLM(openai_compat)로 이벤트 실재·
   필드(event_type·direction 7종·severity 0~3·evidence_quote) 추출. Pydantic
   `GeoEvent` 검증 게이트로 형식 오염(플레이스홀더 echo 등) 차단.
3. **관련성 정제**(2026-07-20~21, `gkg_relevance*`): 2단계 LLM 판정(추출과 분리된
   관련성 전용 프롬프트+2차 적대적 재검증 합의투표)으로 오염률 71.4%→관련성
   99.5%. 181만→29.5만 건. 교훈 4건은 메모리 `gkg_relevance_redesign_260720` 정본.
4. **정본 저장**: parquet store(`geo_data/store`)가 정본, DB는 `geo publish`로
   재발행(양쪽 동기 삭제/적재 규약).
5. 잔존 한계(정직 기재): 2026-07-27 LLM 교차판정에서 오태깅·무관 의심 16/250건
   (6.4%) 관찰 — 정제 전 72% 대비 대폭 감소했으나 0이 아님. severity는 추출
   LLM이 체계적으로 높게 부여하는 경향 관찰(교차판정 리포트 참조).

### 3.2 정형 — 표준화·조인 규약

- **스키마 표준화**: 주간·월간 시계열은 `fact_series(series_code, obs_date, val,
  unit, src)`, 광종 귀속 지표는 `fact_indicator(commodity_code, indicator, freq,
  obs_date, val, src)`로 통일. 관세청은 HS 바스켓→광종 매핑(REE는 Nd 9개 HS코드
  근사 바스켓) 후 월간 중량·금액 집계, 단가 = 금액/중량.
- **as-of(시점정합) 조인**: 월간 지표는 발표 지연을 `avail_date`로 명시(예: OECD
  CLI +45일)하고 주간 패널에 as-of 조인 — 미래 정보 누수 차단. 연간 참조자료
  (USGS 생산점유)는 릴리스 시점 기준 as-of(`geo/refdata.py`, 2022·23·25·26 4개
  릴리스).
- **결측 처리 원칙**: 학습은 결측 행 제거, 예측 시점만 중립 대치 — 워밍업 NaN을
  0으로 채워 학습하면 계수가 오염되는 함정을 실측으로 확인(x_z13 사례). 예측
  모델의 피처 결측은 학습분포 중앙값 대치.
- **표준화·파생**: 주간 z-점수(52주 창, 최소 20주 — price_z52·gsev_z13 등),
  월간 z(24개월 — 아르헨 z24), 전년동월비(yoy)·3개월 변화율(chg3), 로그 변환
  (물량 ly=log1p), 계절성은 월의 사인/코사인 인코딩.

### 3.3 지수화 전처리

- 이벤트를 광종×주간 격자로 집계(성능 규약: row-wise apply 금지, grid+merge).
- 심각 이벤트 수·심각도 가중·신뢰도 가중(conf_weight)·이중노출 잔차(resid) 처리.
- 지수 공식은 tanh 절대스케일(0~100) — 과거값 불변(재앵커는 버전 경계 마커로
  대시보드에 표시). 주간 앵커는 월요일(구 스냅샷 일요일 앵커와의 정합은 +1일
  보정 규약).

## 4. 모델링 과정

공통 검증 원칙(모든 채택의 관문): ① 페어드 부트스트랩 신뢰구간 하한>0
② 이웃 설정(창·지연·모수)·배깅 시드 강건 ③ 데이터 재발행 후 유지(발행본 변동
±0.01~0.03 QWK 초과 개선만 신뢰). 기준선은 광종별 실제 채택 동작점(풀링 피처
기준선의 가짜 유의 함정 코드화 — PER_CC_CHAMP). 자동 피처선정(순열중요도 등)은
다중공선성 함정 실증으로 금지 — 피처는 개별 검정 채택분만.

### 4.1 지정학 급증확률 (geo_prob)

- **패널**: 광종×주간, 타깃 = 다음 주 심각 이벤트 수(y_next).
- **피처(base3)**: `x_ewma`(심각 이벤트 지수가중 이동평균) · `x_geo`(위기지수) ·
  `x_vol`(log1p 주간 총 이벤트 수). **CO만 +`x_z13`**(심각 13주합의 52주 z) 병행.
- **모델**: 음이항(NB2) 회귀(광종별 적합, 과산포 α 추정). 급증확률
  `p_burst_next = P(y_next ≥ burst_k)`, burst_k = 학습기간 P90(정수, 최소 2).
- **적응형 병기(REE 왜곡 해소)**: `k_adapt` = 직전 52주 P90(당주 정보만) 기반
  `p_burst_adapt`를 비파괴 병기 발행 — 고정 임계가 체제전환기(REE 2024+)에
  상시 급증으로 포화되는 왜곡을 해소(0.52→0.12). 확률은 강도 NB2와 상대강도
  로지스틱의 앙상블("보팅은 원천이 다를 때만" 규칙의 적용례).
- 검증: 학습 ≤2023 / 검증 2024+ Brier, 상수 강도 기준선 대비. LI는 격차가
  통계 무차별임을 확정(6변형 전수 기각)하고 현행 유지.

### 4.2 수급위기 진단 — 운영 4단계 경보(레벨)

- **패널**: 광종×주간(총 2,411행), 정답(teacher) = KOMIS 수급동향 기반 4단계
  경보(2020~, 발주처 컷 2026-06-08).
- **피처**: 등급 지속성 `grade_lag1` + 지정학 3종(`geopolitical_risk`·`geo_chg`·
  `p_burst`) + 무역 3종(`import_hhi`·`import_yoy`·`import_cagr3`) + 가격 4종
  (`ref_price`·`volatility_12w`·`spread_pct`·`price_z52`). 가격 이격률 등 신규
  가격 파생은 라벨 순환 오염 검정에서 기각(추가·교체 모두 악화 — price_z52 유지).
- **모델**: Ridge(정칙화 선형) 회귀→등급 매핑+운영 오버라이드(재설계 반영),
  단계 확률은 학습잔차 기반, 설명은 선형 정확 기여 분해(XAI, 법정 사유문 자동
  생성 — out_diagnosis_alert).
- 검증: 워크포워드 3폴드(2023/2024/2025~) QWK 0.9687. 대안(트리·부스팅·전피처·
  부분풀링·y_lag1 대안 6계열 등)은 9차례 전부 기각 — 재시도 금지 목록 관리.

### 4.3 수급위기 진단 — 보조 조기경보(Δ 전환 감지, 병기 신호)

- **타깃**: 주간 등급변화 Δ∈{-1,0,+1}(당주 vs 전주) — 경보 등급을 바꾸지 않는
  병기 신호(hard 결합은 2회 백테스트 기각으로 금지).
- **모델**: 소프트보팅 = Bagging25(Logistic, 채택 동작점 피처 — p_burst 포함)
  + Bagging25(Logistic, p_burst→gsev_z13 대체) — 모델 확률과 원시 이벤트 누적의
  이원 원천 앙상블. 양 멤버 공통 피처: NOLAG(지정학·무역 6종) + LME 재고(INV) +
  중국 거래소 재고(CNINV) + 중국 PMI + **OECD 한국 CLI 3종**(yoy·chg3·z24,
  avail +45일 — R10 채택).
- **광종별 채택 동작점(특화 축)**: CU +SHFE 구리 미결제약정(CNOI) / NI 재고 2축
  (LME+SHFE) / LI +아르헨 수출 z24(조건부 — 보고 산발 시 자동 비활성).
- 발행: 전 기간 재적합 후 최신 관측주 5광종 발행(out_aux_early_warning, v2).
- 검증: 워크포워드 3폴드 QWK 0.889·전환 0.269·FAR 0.145.

### 4.4 12개월 수입물량(ton)·수입단가(unit) 예측

- **패널**: 광종×월(관세청), 타깃 = 월간 수입물량·단가(로그 변환).
- **기본 11피처(BASE)**: lag{1,2,3,6,12} + 최근 3개월 이동평균(roll3) + 계절
  (m_sin·m_cos) + LME 재고 레벨(lme_l) + 지정학(geo_f) + 환율(fx_l) + 광종 더미.
- **혼합주기(MIDAS) 피처(v3~)**: ton은 주간 지정학지수의 지수감쇠 가중합(λ 사전,
  13주 창 — 월평균으로 뭉개던 주간 정보 보존), unit은 가격·환율의 월말 레벨(w0)
  +13주 기울기(slope) — 단가는 가격 전가 구조라 월말 상태가 정보적.
- **모델(v4 확정)**: 직접 다지평(h=1..12 각각 적합, method=direct 채택 — 재귀
  대비 MASE 0.755). ton = ExtraTrees+MIDAS지수+시간감쇠 표본가중(반감기 24개월),
  **CO ton만 ElasticNet+감쇠 hl36**(광종 특화). unit = ExtraTrees+U-MIDAS,
  **NI unit만 +감쇠 hl24 셀 오버라이드**. 구간은 HGB 분위+적합성 보정(conformal,
  실측 커버리지 0.79) — 점추정 교체와 무관하게 유지. 설명은 트리 SHAP/선형 정확
  기여(모델-설명 일치 원칙, CO·NI 분기).
- 검증: 18개 예측 기점 × h1..12 WAPE. 신규 외생 29종 전패(4번째) — lag 지배
  구조 확인, 계절 나이브 대비 최초 역전.
