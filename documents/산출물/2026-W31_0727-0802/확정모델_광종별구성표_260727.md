# 핵심광물 수급위기 진단·수요예측 시스템 — 광종별 확정 운영 모델 구성표

- 작성: 2026-07-27 (수행사)
- 수신: 한국광해광업공단 / KOMIS 담당부서
- 목적: 5개 광종(동·니켈·코발트·리튬·희토류) × 3개 모듈(지정학 위기지수·수급위기
  진단·12개월 수입 예측)의 **최종 확정 운영 모델·입력 데이터·검증 성능**을 한 표로
  정리하여 전달. 2026-07-25~26 집중 개선(별도 보고서 기제출)까지 반영된 확정본.

## 1. 확정의 의미와 기준

아래 구성은 다음 세 가지가 충족되어 "확정"으로 분류한 것입니다.

1. **3중 검증 통과분만 반영**: 모든 채택은 과거 데이터 백테스트에서 ① 부트스트랩
   신뢰구간이 0을 상회(우연 아님) ② 설정 변형(창·지연·시드)에도 유지 ③ 데이터
   재발행 후에도 유지 — 를 통과했습니다. 미달분은 전부 "보류/기각"으로 별도
   관리하며 운영에 반영하지 않았습니다.
2. **개선 탐색이 소진 상태**: 광종×모듈 15개 세부 셀을 전수 실측하여 개선 가능한
   셀은 전부 개선을 완료했고, 나머지 셀은 추가 개선 시도가 통계적으로 무의미함을
   검증으로 확인했습니다(예: 리튬 급증확률 — 6개 변형 전수 검정 후 현행 유지 확정).
   신규 수집 데이터 29종의 예측 투입도 전수 검정 결과 유의한 개선이 없어(월간
   수입은 자기 이력이 지배) 예측 구성이 안정적임을 재확인했습니다.
3. **동결이 아닌 "교체 조건이 명문화된 확정"**: 향후 신규 데이터(협조 요청분 포함)
   가 확보되면 표준 재검정 절차가 수행되며, 위 3중 검증을 통과하는 경우에만 해당
   셀이 교체됩니다(6장).

## 5. 정직한 한계 명기

- **리튬 급증확률**: 단순 기준선 대비 열세로 보이는 0.005 격차는 통계적으로
  무의미함(신뢰구간이 0을 포함)을 확정했습니다. 모델 측 개선 여지가 소진되어,
  실질 개선은 리튬 선행 신호 데이터 확충(EV·배터리 장기 월간 — 협조 요청 목록
  4번)과 연동됩니다.
- **코발트·희토류 진단의 광종 특화 축 부재**: 데이터가 아닌 시간 문제(경보 전환
  사례 표본 부족)로, 표본 축적 시 재검정 예정입니다. 코발트 물량 예측(51%)은
  특화로 대폭 개선됐으나 여전히 5광종 중 최고 오차 — 물량 변동성이 구조적으로
  큰 광종으로, LME 코발트 주간 재고(협조 요청 1번) 확보 시 재검정합니다.
- **리튬 아르헨티나 축의 조건부 채택**: 원천 보고가 산발적(123개월 중 56개월)
  이라 커버리지 조건부로 운영하며, 보고 누락 구간에는 자동으로 비활성화됩니다.

1. 이 구성표는 **2026-07-27 기준 확정본**이며, 주간/월간 자동 수집·발행 체계에서
   이 구성 그대로 무인 운영됩니다.
2. 신규 데이터(발주처 협조 요청분 포함)가 확보되면 표준 재검정 절차(등록형 검정
   하네스)로 **수일 내** 효과를 검증하고, 1장의 3중 검증을 통과하는 경우에만 해당
   셀을 교체 후 변경 이력과 함께 보고합니다.
3. 데이터 품질 이슈(예: 원천 결측·재발행)가 발생해도 모델 구성은 유지되며,
   복구 후 산출물만 재발행됩니다(2026-07-27 중국 거래소 구리 재고 결측 복구·
