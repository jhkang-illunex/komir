# A-5 사람판정 진행 방안 (2026-07-27)

## 1. 목적·배경

A-5 = 외부감사 후속조치의 라벨 품질 검증: LLM이 추출한 geo_event 라벨(severity·
direction·event_type)을 **독립된 사람 판정**과 대조해 Cohen's kappa로 일치도를
측정한다. 핵심 전제는 사람-LLM 독립성이므로 **Claude가 판정을 대신 채우면 검증
자체가 무효**(자기검증) — 2026-07-20에 사용자 승인 하에 만든 참고용 임시채움
(`a5_kappa_report_REFERENCE_ONLY.md`, 명목 kappa: severity 0.43·direction 0.64·
dimension 0.72)은 발주처 보고·감사 대응에 사용 금지 상태 그대로다. 실제 사람
판정만이 잔여 과제이며, 이는 인력·일정 결정이라 자동화가 불가능하다.

## 3. 2026-07-27 실측 — 기존 패키지를 그대로 쓸 수 없는 이유 3가지※

07-18 패키지는 **GKG 정제(07-20~21, 181만→29.5만 건) 이전** 모집단에서 설계됐다.

1. **표본 절반 소멸**: 기존 248건 중 현행 geo_event 생존 **122건(49%)** — 나머지는
   정제로 삭제된 오염 이벤트라, 그대로 판정시키면 공수의 절반이 "이미 시스템에서
   제거된 데이터"에 낭비된다. → **재표집 필수**.
2. **dimension 필드 전량 소실**: 현행 geo_event 296,046건 모두 dimension=None
   (07-18 실측 때는 policy 97.6% 등 존재 — 정제 후 재발행에서 미보존된 것으로
   추정, **원인 추적은 별도 확인 과제**). → 3축 층화(광종×dimension×severity)와
   dimension kappa 판정 항목이 모두 불가 — **판정 항목을 severity·direction·
   event_type 3종으로 재정의**.
3. **검증 목적 자체가 좁혀짐**: 관련성 오염 검증은 별도 트랙에서 이미 종결
   (관련성 99.5%, 2차 적대적 재검증) — A-5는 이제 "관련한 이벤트에 붙은 라벨의
   품질"에 집중하면 된다. 오히려 모집단이 깨끗해져 판정 효율이 오른다(무관
   콘텐츠 골라내기가 아니라 순수 라벨 판정).

참고: event_type은 표준값과 자유서술이 혼재('뉴스' 10.3만·'정책'/'policy'/
'Geopolitical/Policy' 병존) — 판정 항목은 "적절성 Y/N/부분" 유지가 맞고, 값
표준화는 A-5 밖의 별도 과제로 분리한다.

## 4. 진행 방안 (단계별)

### 0단계 — 패키지 최신화 ✅완료(2026-07-27, B안 확정 — WORKLOG 최신㊳)

재표집 250건(광종별 50·severity 셀 12~14 균형) 완료. 검토자 배포 파일:
`outputs/model_opt/a5_review_A_260727.csv`·`a5_review_B_260727.csv`(LLM 판정값
미포함 — 앵커링 원천 차단), 가이드 `a5_labeling_guide_v2_260727.md`. 채점기는
2인 교차·사람간 kappa 지원으로 확장, 합성 데이터로 전 경로 검증 완료. **다음
액션 = 검토자 A·B 지정·배포(1단계)뿐.** 원래 계획은 아래(기록 보존):

- `a5_label_review_sample.py` 층화축을 **광종(5)×severity(0~3)** 2축으로 수정,
  현행 모집단(29.6만)에서 240~250건 재표집(희소 광종 CO 4,546·REE 3,641건은
  균등 예산 유지, severity=3 희소층 6,348건 우선 확보).
- 라벨링 가이드 개정: dimension 절 삭제, event_type 비표준값 안내 추가.
- 판정 CSV 재생성(빈 판정칸). **참고용 임시채움은 재생성하지 않음** — 사람 판정
  완료 후 비교가 필요하면 그때 별도 수행(사전 채움은 앵커링 위험만 있음).

### 1단계 — 검토자 결정 (사용자/조직 결정 필요 — 이 문서의 핵심 결정사항)

| 옵션 | 구성 | 공수 견적 | 얻는 것 | 리스크 |
|---|---|---|---|---|
| A. 내부 1인 | 프로젝트 외 내부 인력 1명 | 250건×1~2분 ≈ **반일~1일** (파일럿 포함) | LLM vs 사람 kappa(최소 요건 충족) | 판정자 1인 편향 통제 불가 |
| **B. 내부 2인 교차(권장)** | 2명이 동일 표본 독립 판정 | 1인당 반일~1일 | + **사람간 kappa(기준선)** — LLM kappa의 해석 기준점(사람끼리 0.6이면 LLM 0.6은 준수하다는 논거) — 감사 방어력 최상 | 인력 2명 확보 |
| C. 발주처(KOMIS) 전문가 | 발주처 도메인 전문가 1인+ | 발주처 일정 의존 | 발주처가 직접 검증한 라벨 품질(수용성 최상) | 일정 통제 불가 — **협조 요청 안건으로 병행 제안만** |

권장 조합: **B로 즉시 진행 + C는 발주처 요청 목록에 "라벨 판정 참여" 항목으로
병행 제안**(B 결과를 먼저 확보해 두면 C는 보너스).

### 2단계 — 파일럿 → 본판정 (검토자 확정 후 1주 내)

1. 파일럿 20건: 검토자가 가이드만 보고 판정 → 30분 리뷰 미팅에서 가이드 모호점
   보정(기준 변경은 파일럿까지만 허용, 본판정 중 변경 금지).
2. 본판정 220~230건: 검토자는 `evidence_quote` 원문만 보고 판정(LLM 라벨 열은
   시트에서 숨김 — 가이드의 앵커링 방지 절차 준수). 판단 불가는 빈칸이 아니라
   "판단불가"로 명시 기입.

### 3단계 — 채점·보고 (판정 완료 후 반일, Claude 수행)

- `a5_kappa_score.py`로 채점(severity=quadratic-weighted, direction=nominal,
  event_type=Y/N/부분 집계; 옵션 B면 사람간 kappa 추가 산출).
- 리포트 작성 → 스코어카드 반영 → 발주처 통합 보고서의 "3중 검증" 절에 편입.
  이때 REFERENCE_ONLY 임시채움과의 대조(Claude 판정 vs 사람 판정)도 부록으로
  가능 — 임시채움의 유일한 정당한 용도.

### 성공 기준 — 판정 시작 전 합의(사후 설정 금지)

Landis-Koch 기준으로 **사전에** 고정할 것을 제안: severity weighted kappa ≥0.4
(moderate)면 수용, ≥0.6(substantial)이면 양호, <0.4면 라벨 재설계 트리거.
direction ≥0.6, event_type 적절성 ≥80%. (참고: 임시채움의 명목치가 0.43/0.64/
82%였으므로 현실적인 선 — 단 임시채움은 근거로 인용하지 않는다.)
