# 광물자원가격 > 철광석 및 에너지

- **page_id**: `price_iron_energy`
- **API**: `POST /api/v1/analysis/prices/iron-energy`
- **화면 위치**: 요약보고서 작성 데모(`inhouse/streamlit_demo/views/report_demo.py`) — 주메뉴 `광물자원가격` → 서브메뉴 `철광석 및 에너지`

## 1. 이 메뉴에서 선택 가능한 옵션

- **광종**: 드롭다운, 필수 — 소스: KOMIS 실측 registry `metadata.prices.iron_energy.minerals`(3종: 우라늄·유연탄·철, ai_mnrl_mst엔 2종뿐이라 registry로 대체)
- **비교광종(compare_mineral)**: 선택 — KOMIS registry(3종) 드롭다운(기본 **비교하지 않음**) — 이번 실행도 미선택
- **원자료 입력 방식**: KOMIS 원본 JSON 붙여넣기(`가격 조회 결과(getMnrlPrcByMnrkndUnqCd)`) — 사람이 komis.or.kr에서 직접 조회한 원본을 그대로 붙여넣으면 report_gen이 파싱(observations 수동 입력 방식이 아님)
- **참고**: forecast_price(가격예측)·price_group(그룹 요약)은 이 데모 화면에 메뉴 자체가 없어 선택할 수 없음(META.md 참고)
- **평균 옵션**: 일간(DAY) / 주간(WEEK) / 월간(MONTH) / 분기간(QUARTER) / 년간(YEAR) 중 선택
- **기간 구분자**: 년간(year) / 월간(month) 중 선택
- **기간(시작~종료)**: 기간 구분자에 따라 연도(2000~올해) 또는 월(2000-01~이번달) 콤보박스
- **komis.or.kr에서 실시간 조회** 버튼 — 위 옵션으로 KOMIS(`getMnrlPrcByMnrkndUnqCd`)를 직접 호출해 "KOMIS 데이터 조회 결과" 칸을 채운다(이 데모 한정 DMZ/inhouse 원칙 예외, 사용자 승인)

## 2. 이번 실행에 사용한 옵션값

- 광종: **철(MNRL1011)**(원본 JSON이 실제로 담고 있는 광종과 일치)
- **기간(사용자 지시 반영, 2026-09-08 재작성)**: 최근 1년 — 평균 옵션 `DAY`(일간), 기간 구분자 `month`(월간), 2025-09 ~ 2026-09
- **원자료**: 정적 예시가 아니라 komis.or.kr을 이번 실행 시점에 **실시간 조회**(`komis_fetch.fetch_price_iron_energy`)해 받은 실데이터 — 관측치 **246건**(영업일 기준 약 1년치)
- 그 외 옵션: UI 기본값 그대로(compare_mineral 미선택) — report_gen에 실린 요청 바디 필드: `komis_response, mineral, mineral_name`
