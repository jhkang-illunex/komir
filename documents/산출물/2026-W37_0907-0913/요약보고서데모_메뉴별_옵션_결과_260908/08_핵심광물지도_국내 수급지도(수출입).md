# 핵심광물지도 > 국내 수급지도(수출입)

- **page_id**: `map_korea`
- **API**: `POST /api/v1/analysis/maps/domestic-trade`
- **화면 위치**: 요약보고서 작성 데모(`inhouse/streamlit_demo/views/report_demo.py`) — 주메뉴 `핵심광물지도` → 서브메뉴 `국내 수급지도(수출입)`

## 1. 이 메뉴에서 선택 가능한 옵션

- **광종**: 드롭다운, 필수 — 소스: KOMIS 실측 registry `metadata.maps.trade_minerals`(73종, ai_mnrl_mst 아님)
- **조회방향(trade_direction)**: 수입 / 수출 중 선택(기본값 **수입**)
- **원자료 입력 방식**: KOMIS 원본 JSON 붙여넣기(`국가별 목록 조회 결과(getListKoreaData)`) — 사람이 komis.or.kr에서 직접 조회한 원본을 그대로 붙여넣으면 report_gen이 파싱(이 페이지는 observations 수동 입력 방식이 아님)
- **참고**: forecast_price(가격예측)·price_group(그룹 요약)은 이 데모 화면에 메뉴 자체가 없어 선택할 수 없음(META.md 참고)
- **기간 구분자**: 년간 / 월간 중 선택
- **기간(시작~종료)**: 년간이면 연도(2021~2026) 콤보박스 2개, 월간이면 연도+월 콤보박스 각 2쌍(2단계 흐름)
- **국가명**: 텍스트 입력, 선택(기본 전체)
- **생산품 유형**: 드롭다운, 선택(기본 전체) — 광종 선택 시 KOMIS에서 동적 조회
- **HS코드**: 드롭다운, 선택(기본 전체) — 광종+생산품 유형 선택 시 동적 조회
- **komis.or.kr에서 실시간 조회** 버튼 — `getListMttrFlow`/`getListOnlyHsCode`/`getNatInfoCodeList` 3개 엔드포인트 호출

## 2. 이번 실행에 사용한 옵션값

- 광종: **갈륨(MNRL0024)**(원본 JSON 예시가 실제로 담고 있는 광종과 일치시킴)
- 그 외 옵션: UI 기본값 그대로(기간 공란, compare_mineral 미선택 등) — 실제로 report_gen에 실린 요청 바디 필드: `komis_response, mineral, mineral_name, trade_direction`
- 원자료: `inhouse/streamlit_demo/komis_raw.py`의 `KOMIS_RAW_PAGES["map_korea"].example_raw_json`(라이브 실측 캡처, 상세 출처는 그 파일 주석 참고)
