# 핵심광물지도 > 광물지도(매장량/생산량)

- **page_id**: `map_mineral`
- **API**: `POST /api/v1/analysis/maps/mineral`
- **화면 위치**: 요약보고서 작성 데모(`inhouse/streamlit_demo/views/report_demo.py`) — 주메뉴 `핵심광물지도` → 서브메뉴 `광물지도(매장량/생산량)`

## 1. 이 메뉴에서 선택 가능한 옵션

- **광종**: 드롭다운, 필수 — 소스: `public.ai_mnrl_mst`(전체 19종, 필터 없음)
- **측정지표(measure)**: 매장량(reserves) / 생산량(production) 중 선택(기본값 **매장량**)
- **단위(unit)**: 텍스트 입력(기본값 **천톤**)
- **원자료 입력 방식**: KOMIS 원본 JSON 붙여넣기(`광물지도 조회 결과(getListMapMnrlChartData+getListMapMnrlData+getListMnrlTablePrdctnBurgudg)`) — 사람이 komis.or.kr에서 직접 조회한 원본을 그대로 붙여넣으면 report_gen이 파싱(이 페이지는 observations 수동 입력 방식이 아님)
- **참고**: forecast_price(가격예측)·price_group(그룹 요약)은 이 데모 화면에 메뉴 자체가 없어 선택할 수 없음(META.md 참고)
- **기간(시작~종료)**: 연간, 2021~2025 콤보박스 2개
- **komis.or.kr에서 실시간 조회** 버튼 — `getListMapMnrlChartData`+`getListMapMnrlData`+`getListMnrlTablePrdctnBurgudg` 3개 엔드포인트를 묶어 호출

## 2. 이번 실행에 사용한 옵션값

- 광종: **동(MNRL0008)**(원본 JSON 예시가 실제로 담고 있는 광종과 일치시킴)
- 그 외 옵션: UI 기본값 그대로(기간 공란, compare_mineral 미선택 등) — 실제로 report_gen에 실린 요청 바디 필드: `komis_response, komis_share_response, komis_snapshot_response, measure, mineral, mineral_name, unit`
- 원자료: `inhouse/streamlit_demo/komis_raw.py`의 `KOMIS_RAW_PAGES["map_mineral"].example_raw_json`(라이브 실측 캡처, 상세 출처는 그 파일 주석 참고)
