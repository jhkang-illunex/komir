# 광물전망지표 > 광물종합지수

- **page_id**: `indicator_composite`
- **API**: `POST /api/v1/analysis/indicators/composite-index`
- **화면 위치**: 요약보고서 작성 데모(`inhouse/streamlit_demo/views/report_demo.py`) — 주메뉴 `광물전망지표` → 서브메뉴 `광물종합지수`

## 1. 이 메뉴에서 선택 가능한 옵션

- **광종**: 없음(이 페이지는 광종 비종속 — 종합지수 자체가 대상)
- **원자료 입력 방식**: KOMIS 원본 JSON 붙여넣기(`광물종합지수 조회 결과(getLineChartIndx)`) — 사람이 komis.or.kr에서 직접 조회한 원본을 그대로 붙여넣으면 report_gen이 파싱(이 페이지는 observations 수동 입력 방식이 아님)
- **참고**: forecast_price(가격예측)·price_group(그룹 요약)은 이 데모 화면에 메뉴 자체가 없어 선택할 수 없음(META.md 참고)
- **실시간 조회 버튼**: 없음 — KOMIS AJAX가 페이지 URL(`IndxMin`)과 다른 세션 경로(`IndxMinDex`)를 쓰고 동일출처 쿠키가 필요해 `komis_fetch.py`에 아직 구현돼 있지 않음(라이브 실측 캡처를 예시로 붙여넣는 방식만 지원)

## 2. 이번 실행에 사용한 옵션값

- 그 외 옵션: UI 기본값 그대로(기간 공란, compare_mineral 미선택 등) — 실제로 report_gen에 실린 요청 바디 필드: `komis_response`
- 원자료: `inhouse/streamlit_demo/komis_raw.py`의 `KOMIS_RAW_PAGES["indicator_composite"].example_raw_json`(라이브 실측 캡처, 상세 출처는 그 파일 주석 참고)
