# 광물전망지표 > 시장동향지표

- **page_id**: `indicator_market`
- **API**: `POST /api/v1/analysis/indicators/market`
- **화면 위치**: 요약보고서 작성 데모(`inhouse/streamlit_demo/views/report_demo.py`) — 주메뉴 `광물전망지표` → 서브메뉴 `시장동향지표`

## 1. 이 메뉴에서 선택 가능한 옵션

- **광종**: 드롭다운, 필수 — 소스: KOMIS 실측 registry `metadata.indicators.market_minerals`(39종, ai_mnrl_mst 아님 — DB 19종에 없는 광종 다수 포함)
- **조회기간(start_month/end_month)**: 텍스트 입력 2칸, 선택(형식 YYYY-MM) — 이번 실행은 공란(UI 기본값)
- **원자료 입력 방식**: KOMIS 원본 JSON 붙여넣기(`시장동향지표 조회 결과(getListIndxMnrk)`) — 사람이 komis.or.kr에서 직접 조회한 원본을 그대로 붙여넣으면 report_gen이 파싱(이 페이지는 observations 수동 입력 방식이 아님)
- **참고**: forecast_price(가격예측)·price_group(그룹 요약)은 이 데모 화면에 메뉴 자체가 없어 선택할 수 없음(META.md 참고)
- **실시간 조회 버튼**: 없음 — 로그인 필요 페이지라 자동화 조회 경로 미보유(2026-09-01 발주처가 제공한 원본 JSON을 붙여넣는 방식만 지원)

## 2. 이번 실행에 사용한 옵션값

- 광종: **갈륨(MNRL0024)**(원본 JSON 예시가 실제로 담고 있는 광종과 일치시킴)
- 그 외 옵션: UI 기본값 그대로(기간 공란, compare_mineral 미선택 등) — 실제로 report_gen에 실린 요청 바디 필드: `komis_response, mineral, mineral_name`
- 원자료: `inhouse/streamlit_demo/komis_raw.py`의 `KOMIS_RAW_PAGES["indicator_market"].example_raw_json`(라이브 실측 캡처, 상세 출처는 그 파일 주석 참고)
