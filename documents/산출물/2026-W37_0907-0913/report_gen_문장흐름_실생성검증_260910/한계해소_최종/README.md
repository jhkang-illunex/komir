# 남은 문장 품질 한계 수정 완료

2026-09-10 테스트 API `komir-report-gen-test`에서 동일 KOMIS 덤프로 재검증했다. 최종 선택한 4종 모두 HTTP 200 / status=ok / llm_refined=True이며, 중간 희소금속 폴백 1건도 원자료와 로그에 보존했다.

## 확인된 수정

- 희소금속: `전월평균 대비 9.60% 낮고, 전년평균 대비 27.03% 높습니다.`로 비교 방향 명시. 동일 값은 `같은 수준입니다`로 표현.
- 최근 변화: 전체 조회기간 변화를 먼저 설명하고 `최근에는 2일 연속 하락세를 보이고 있으며, 단기와 중기 가격 흐름이 엇갈리고 있습니다.`로 연결. LLM 없이도 동일한 순서·연결을 사용하며 evidence_ids 3개 보존 확인.
- 종합지수: `조회기간 최고치인 3,539.45포인트와 같으며`로 변경. 최고·최저·전체 동일 값 3개 분기를 확인.
- 시장지표: `직전월보다 21.69점 올랐습니다.`로 변경. 상승·하락·변동 없음 분기 확인.

기존 회귀 테스트 14개 통과, 방향/고저점 9개 분기 검사 및 기본 문장 연결·근거 보존 검사 통과. 최종 4개 보고서의 주요 지표 표는 같은 입력의 규칙 기반 계산 결과와 일치했다. 숫자 크기 집합에서도 새 수치가 없었다(부호 대신 높고/낮고를 쓰므로 크기를 비교하고, 대표 비교 방향은 원문으로 확인). git diff --check 통과.

수정 소스와 가격 프롬프트는 테스트 컨테이너에 반영했고 DB 가격 프롬프트는 백업 후 갱신했다. 새 이미지 빌드나 별도 운영 서버 배포는 수행하지 않았다. 검증 범위는 요청된 남은 문장 문제와 동일 표본 4종이다.

생성 원문은 각 page_id.md, 결과는 checks.json, LLM 성공 여부는 llm_validation.log에서 확인할 수 있다.
