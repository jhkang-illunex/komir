# 보고서 문장 흐름 실제 생성 검증

후속 작업으로 아래에 기록된 문장 품질 한계를 수정 완료했다. 최신 결과는 [한계 해소 최종 검증](한계해소_최종/README.md)을 참조한다. 아래 내용은 최초 검증 당시의 기록이다.

2026-09-10, `komir-report-gen-test`의 실제 HTTP API와 연결된 LLM으로 검증했다. 신규 KOMIS 조회 대신 저장소 `income_data/komis`의 실제 응답 덤프를 입력했다. 각 파일의 results[0]을 사용했다.

## 수정 및 확인

- 공통 지침에서 같은 주제의 근거만 연결하고 불필요한 주어·종결어 반복을 줄이도록 정리했다.
- 가격 지침의 원문 복사와 문장 연결 사이의 충돌을 해소하고, 실제 출력에서 발견한 어색한 활용 교정 예시를 추가했다.
- `komir_summary.py`의 근거 문구도 `낮음으로` → `낮으며`, `최근 가격 흐름은 단기와 중기 흐름이 엇갈리는 상태입니다` → `최근에는 단기와 중기 가격 흐름이 엇갈리고 있습니다`로 수정했다. LLM을 사용하지 않는 경우에도 적용된다.
- 가격 프롬프트 4개 DB 행을 기존 백업 테이블에 보관한 후 갱신하고 reload했다. 최종 공통·가격 5개 키는 소스 파일과 모두 일치했다.
- 근거 문구 수정은 실행 중인 테스트 컨테이너에도 적용하고 재시작했다. 새 이미지 빌드 및 별도 운영 서버 배포는 수행하지 않았다.
- 최종 4개 보고서의 주요 지표 표는 같은 입력의 규칙 기반 계산 결과와 모두 일치했다. 본문을 포함한 숫자 집합 비교에서도 새 숫자가 발견되지 않았다. 이는 숫자의 모든 문맥·관계를 독립적으로 증명하는 검사는 아니며, LLM 근거 검증 통과 여부는 서버 로그로 함께 확인했다.
- 회귀 테스트 14개 통과. 샌드박스 내 HTTP 테스트가 멈춰 제한 시간 40초를 둔 샌드박스 밖 동일 검사로 확인했다. git diff --check 통과.

## 남은 품질 한계

`낮음으로`와 중복된 `가격 흐름` 표현은 최종 가격 2건에서 사라졌다. 다만 희소금속은 여전히 `전월평균 대비 -9.60% 수준`처럼 비교 방향을 부호로만 표현하고, 최근 변화 문장은 개별 문장으로 나열하는 경향이 남아 있다. 따라서 실제 생성·수치 보존·확인된 문법 수정은 검증했으나, 모든 문장의 자연스러움이 완전히 해결됐다고 판단하지 않는다. 종합지수의 `최고치보다 0.00% 낮고`, 시장지표의 `21.69점 올라 움직였습니다`도 후속 문장 품질 개선 대상으로 남긴다.

각 page_id.md는 실제 최종 출력, page_id_baseline.md는 동일 입력의 로컬 규칙 기반 출력, checks.json은 비교 결과다. 표본은 4종으로 전체 광종·기간 조합을 대표하지 않는다.
