# 핵심광물지도 — 날짜 외 옵션(국가·생산품유형·교차비교) 확인 (2026-09-13)

> 배경: "핵심광물 지도에서는 더 테스트할 케이스가 없나요? 날짜 말고 국가
> 생산품 유형 같은 옵션을 바꿔 가면서 체크해봐주세요." — 지금까지(오늘
> 오전 풀 검증 포함) map_korea/global/mineral은 전부 "광종 하나 고르고
> 날짜범위 전체"만 테스트했다. `AnalysisSummaryRequest`/`komis_response`가
> 지원하는데 한 번도 안 써본 필드가 더 있는지 모델 코드를 직접 훑어
> 찾아냈다 — 아래 3가지는 전부 이번에 **처음** 실제로 켜본 옵션이다.

## 찾아낸 미검증 옵션 3가지

1. **map_korea — 국가/생산품유형/HS코드 조회필터**: KOMIS `getListKoreaData`는
   조회 시 쓴 필터(국가·생산품유형·HS코드)를 응답 최상위에 그대로
   echo한다. 정적 덤프 8종엔 필터가 걸린 캡처가 하나도 없어(전수 확인),
   실제 KOMIS 동작 규칙(모델 코드에 문서화됨 — 국가필터시 `sumIncmAmt`가
   그 국가 자체 금액과 일치, 범위필터시 부분소계)에 따라 "전체기간"
   응답에서 합성했다.
2. **map_global — `komis_route_share_response`**(`getListMapNationData`,
   원산국↔도착국 루트별 각자 집계총액 대비 비중): 정적 덤프에 **실제로
   캡처돼 있었다**("...|map" 키, 73개 광종 전부) — 지금까지 아무도 이
   필드를 전달한 적이 없어 화면의 "주요 교역 루트"·"한국 관련 루트"
   절이 한 번도 실제로 렌더링된 적이 없었다.
3. **map_mineral — `komis_snapshot_response`**(`getListMapMnrlData`, 국가별
   매장량·생산량 동시 스냅샷 → "매장량 2위 국가는 생산량 몇 위" 교차비교)
   **`komis_share_response`**(`getListMnrlTablePrdctnBurgudg`, KOMIS 공식
   상위 5개년 비중표) — 둘 다 정적 덤프에 **실제로 캡처돼 있었다**("...|map"·
   "...|table" 키, 매장량·생산량 각각 65개 광종). 이 조합도 지금까지 한
   번도 실행된 적이 없었다.

### map_global 루트공유 4건 — 전부 `ok`, 새 절 2개 정상 렌더링

동·니켈·코발트·희토류 4개 광종 전부 `status: ok`. "주요 교역 루트"(글로벌
1~3위 원산국→도착국)·"한국 관련 루트"(대한민국이 포함된 루트 순위) 절이
난생 처음 실제로 나오는 걸 확인 — 예: "동 1위는 칠레→중국 루트 약
2,027.52억 달러(7.22%)... 대한민국이 포함된 교역 루트는 16위 대한민국→
중국 루트 약 246.17억 달러(0.88%)".

### map_mineral 교차비교+공식비중표 — 표본 2건 실HTTP `ok` + **130개 조합 전수 in-process 확인**

표본(동 매장량·니켈 생산량) 실HTTP로 "매장량 2위인 호주는 생산량 기준
8위(약 575만톤, 4.46%)에 그치고 있어..." 같은 교차비교 문장을 확인 —
원본 스냅샷에서 직접 재계산(호주 동 생산량 5,750,000톤/세계 129,000,000톤
=4.46%, 순위 8위)해 정확히 일치함을 대조.

이 교차비교 문장은 `" ".join(cross_facts)`로 최대 3개 국가 문장을 합치는
구조라 — 오늘 오전 발견·수정한 `leading_country_changes` 300자 초과
버그와 **같은 패턴**이다. 그 버그가 재발할 위험이 있다고 보고 **매장량·
생산량 둘 다 캡처된 130개 (광종,측정항목) 조합 전부**를 in-process로
돌려봤다: **104건 `ok`, 26건 정상 `NO_DATA`류(raw 스냅샷 자체가 0행이라
당연한 응답 — 위 오전 결과와 같은 원인), `INTERNAL_ERROR`·300자 초과
`ValidationError` 0건**. 이 패턴의 버그는 이번엔 재발하지 않았다는 것을
확인했다.
