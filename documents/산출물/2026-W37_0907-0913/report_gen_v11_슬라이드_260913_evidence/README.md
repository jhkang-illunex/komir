v10.pptx(22슬라이드)를 복사한 뒤 **스크립트 하나**(`build_v11_full.py`)
로 전체 23슬라이드를 처음부터 다시 생성했다 — 복붙 원칙(2026-09-13 앞선
지적 "슬라이드는 결과물을 복붙만 해야지 고치면 안되요")을 지키기 위해,
이후 슬라이드 텍스트/표를 스크립트 밖에서 손으로 고치지 않았다(값이
안 맞으면 스크립트를 고쳐 처음부터 재실행).

## 신규: 수급동향지표 기본/옵션추가 분리

기존 v10은 수급동향지표(광물전망지표)를 komis_snapshot_response(패널
차트) 옵션이 "이미 적용된" 확장판 1개 슬라이드로만 보여줬다 — 옵션을
안 넣은 기본 버전과 비교할 짝이 없었다. v11은 이를 2개로 분리:

- **기본**(슬라이드13, PPT 표시): 가격리스크 1개 요인만("최근 한 달
  동안 가격은 0.36% 내렸습니다.")
- **옵션추가**(슬라이드14): 패널차트를 더하면 세계수급비율·국내수입
  증가율·국내수입국편중도·세계공급편중도까지 4개 요인이 추가로 드러남

광물종합지수·시장동향지표는 report_gen API 자체에 옵션 필드가 없어서
(`extra_fields=()`, `komis_snapshot_response`는 `map_mineral`/
`indicator_supply` 전용으로 모델 검증기에 막혀 있음 — 직접 확인) 기존
단일 슬라이드를 유지했다. 사용자가 로그인 필요 화면이라 Playwright로도
확인 못 해 직접 검증하겠다고 확정.

## 전체 재생성 과정에서 발견한 실제 버그 2건

1. **소수점 트림 미반영**: 이전에 저장해둔 report_gen 응답 JSON들이
   오늘 앞서 배포한 "소수점 2번째 자리가 0이면 생략" 규칙(_number/
   _quantity 트림) **이전** 시점 캡처라 "45.70%"류 표기가 남아있었다 —
   전부 재조회해 해결(캐시 재사용 금지, 매번 report_gen 최신 코드로
   다시 호출).
2. **국내수급지도 국가필터 총액 산출 버그(진짜 실버그, v10부터 있었음)**:
   `_parse_komis_map_korea_response`가 `sumIncmAmt`를 응답 **최상위**가
   아니라 **행(row) 자체**의 필드에서 읽는데, 지금까지의 슬라이드 빌드
   스크립트는 봉투(envelope)의 `sumIncmAmt`만 덮어쓰고 남긴 단일 행의
   `sumIncmAmt`(원래 전체 국가 합계 값)는 그대로 둬서, "칠레 한정 조회"
   인데 표시되는 총액이 실제로는 **전체 국가 합계**로 나왔다(v10
   슬라이드14: "칠레 대상 수입액 총 약 1,434.77억 달러" — baseline
   전체총액보다도 훨씬 큰, 명백히 잘못된 값. 원인은 그 슬라이드가
   "전체기간"(2014~2026 누적) 데이터를 썼기 때문에 더 크게 부풀려져
   있었다). 행 자체의 `sumIncmAmt`/`sumExpAmt`도 함께 덮어써 수정 —
   이제 "칠레 대상 수입액 약 25.46억 달러"로, baseline의 "1위 수입국은
   칠레 약 25.46억 달러"와 정확히 일치한다.

## 부수 개선

- 국내수급지도 총액 표 셀의 억/만 단위를 자동 선택하도록 수정
  (`compact_currency_fmt`) — 국가필터처럼 총액이 작아지는 경우
  "0.04억"처럼 본문 서술("380.21만원")과 어긋나던 걸 해소.
- 랭킹이 존재하지 않는 국가필터 행(1위/2위/3위 수입국 비중 등)은
  빈 칸 대신 "-"로 명시.

## 정정(같은 날, 사용자 지적) — 수급동향지표 "기본/옵션추가" 분리 되돌림

"수급 동향 지표는 komis_response가 들어간게 기본인데, 값이 없거나
할때만 표시 안되야 함" — 패널차트(komis_snapshot_response)는
compare_mineral·국가필터처럼 KOMIS 화면에서 사용자가 켜고 끄는 진짜
"옵션"이 아니라, 정상적으로 조회하면 늘 함께 오는 기본 데이터라는
지적. 구성요소가 안 보이는 경우는 "옵션을 안 넣어서"가 아니라 해당
요인의 원천 데이터가 그 광종에 한해 실제로 비어 있을 때(예: 세계수급
비율 subChart05가 일부 광종에서 빈 배열)여야 맞다 — 앞서 만든 "기본
(옵션없음)" 슬라이드는 실제로 있을 수 없는 가짜 시나리오였다.

**조치**: "기본/옵션추가" 2슬라이드 분리를 되돌리고, 전체 구성요소가
반영된 버전(패널차트 포함) 하나만 "수급동향지표 - 광물전망지표"라는
원래 제목·캡션으로 유지한다(v10과 동일한 단일 슬라이드 구성으로
복귀, 단 소수점 트림 등 다른 수정사항은 그대로 반영). 총 23슬라이드
(24 → 23, 국가필터 신규 슬라이드는 그대로 유지).

## 후속 추가 2(같은 날, 사용자 지적) — 국내수급지도 "수입/수출 추이" 절 누락

"국내수급지도 - 핵심광물지도 에서 수입, 수출 옵션에서 데이터 변화량에
대한 내용이 수입/수출 현황에 표시 되어야 하는데 없네요" — KOMIS
map_korea 화면엔 "수입규모 추이" 차트가 항상 함께 있다(옵션 아님,
직전 수급동향지표 교훈과 같은 결). report_gen엔 이미 이 추이를
문장으로 만드는 기능(`trade_scale_trend_fact`, 2026-09-10 신설)이
있었지만 `komis_history_responses`(과거 5개년 원본)를 실어야만
동작하는데, 이 세션의 map_korea 슬라이드 3개(baseline·국가필터·
생산품유형필터) 전부 이 필드를 한 번도 보낸 적이 없어 추이 문장이
계속 빠져 있었다.

**조치**: 세 슬라이드 모두 최근 5개년(2022~2026) 히스토리를 실어
재조회 — baseline·국가필터(칠레)는 정적 덤프(`동|수입|YYYY|list`,
2022~2025)에서, 생산품유형필터(기초금속)는 정적 덤프에 없어 4개년
추가 라이브 조회(`cu_map_korea_scope_2022~2025.json`, 이 폴더 보존).
국가필터는 연도별 원본에서 칠레 행만 추출하며 오늘 앞서 고친
"행 자체의 sumIncmAmt/sumExpAmt도 같이 덮어써야 한다" 버그를 그대로
적용(안 그러면 과거 연도도 전체 국가 합계로 잘못 나온다).

세 슬라이드 모두 "수입/수출 추이"라는 새 절을 만들어 담았다(기존
"수입 집중도"와 섞이지 않게 분리) — `rebuild_map_korea_slide()`가
major_changes 중 "최근 N개년... 추이는" 패턴 문장을 자동 감지해 별도
절로 뽑아내고, 없으면(히스토리 확보 실패) 기존 3절 구조로 자동
폴백한다.
