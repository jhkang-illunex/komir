# ③ 주요 지표 산출표 (2026-09-09)

## 무엇인가

발주처 업무지시서 §2.4/§5-6이 요구하는 산출물 중 ③번 — 10개 page_id가
`AnalysisSummaryResponse.key_metrics`/`detailed_metrics`에 싣는 지표별로
**지표명·산식·입력 필드·단위·예외처리 기준**을 정리한다. `key_metrics`는
응답 표 상한(`KEY_METRICS_MAX_COUNT`=14)이 있어 일부는 `detailed_metrics`
(상한 없음, 표에는 안 실리고 API 응답에만 포함)로만 나간다 — 표 열에 그
구분을 표기했다.

**작성 원칙**: 아래 산식은 코드(`komir_summary.py`/`summary.py`/
`additional_summary.py`)를 직접 읽어 옮겼다 — 임의 서술 없음.

기호: `_number(x)` = 소수 2자리 고정 표기, `_quantity(x)` = 정수면 소수점 생략,
아니면 2자리 표기.

## price_base_metals / price_minor_metals / price_iron_energy / price_other

계산기: `komir_summary.py::calculate_price_summary`. 입력의 공통 기반은
`request.komis_response`(있으면 `getMnrlPrcByMnrkndUnqCd` 원본 파싱) 또는
`request.observations`(수동 조립) — 필드별 표에서는 계산에 직접 쓰이는
추가 입력만 표기한다. `주요 지표` 표는 렌더링되지 않지만(§3.1 발주처
지시로 제외) `key_metrics`/`detailed_metrics` 자체는 계속 API 응답에
실린다.

| 지표 ID | 지표명 | 산식 | 입력 필드 | 단위 | 예외처리 기준 |
|---|---|---|---|---|---|
| `latest_price` | 최신 가격 | 최신 관측치 `commerce_price` | observations(최신) | `price_unit`(USD→달러/CNY→위안 매핑, 없으면 미표기) | `commerce_price is None`이면 계산기 자체가 `ValueError`(NO_DATA) |
| `day_over_day_change_pct` | 전일대비/직전관측치대비 | `(최신-직전)/직전 × 100` | observations(최신 2건) | % | 직전 관측치의 `commerce_price`가 없으면 생략 |
| `week_avg_change_pct`/`month_avg_change_pct`/`year_avg_change_pct` | 전주/전월/전년평균대비 | `komis_period_comparisons`가 있으면 KOMIS 제공 `change_pct/100`, 없으면 `(최신-창평균)/창평균`(창=직전 N일 이내 관측치 평균, N=7/30/365) | `komis_period_comparisons`(선택) 또는 observations | % | 조회기간 폭이 N일의 60% 미만이면 계산 안 함(`_PERIOD_COVERAGE_RATIO=0.6`); 창 안에 관측치가 없거나 이미 다른 기간과 같은 관측일 집합이면 생략 |
| `price_streak_length` | 연속 추세 기간 | 최신 관측치부터 역순으로 같은 방향(상승/하락/보합)이 이어지는 관측 횟수 | observations | 일/주/개월(관측 간격 중앙값 기준) | 연속 2회 미만이면 생성 안 함 |
| `period_high`/`period_low` | 최고가/최저가 | `hghstPrc`/`lowstPrc`가 전 관측치에 유효(0·None 아님)하면 그 값, 아니면 `commerce_price` 범위로 대체 | observations | price_unit | 관측치 자체가 없으면 생략(`no_price_range`로 폴백) |
| `drawdown_from_period_high_pct` | 고점 대비 낙폭 | `abs((최신가-조회기간중 최고가)/최고가) × 100`(러닝피크 방식, `_drawdown_stats`) | observations(2건 이상) | % | 관측치 2건 미만이면 계산 안 함 |
| `recent_volatility_pct` | 변동성(최단 가용 창, 연율화) | 일별 수익률 표준편차 × `sqrt(연간 관측횟수)` × 100, 창 3종(1개월/3개월/1년) 중 `_VOLATILITY_WINDOWS` 순서상 먼저 있는 것만 표에 싣는다 | observations | % | 창 안 관측치 5건 미만 또는 조회기간이 창의 60% 미만이면 그 창은 skip |
| `inventory_level` | 재고량 | 최신 관측치 `inventory`(0·None이면 결측 취급) | observations(LME 6대 비철금속만 유효값 제공) | 톤(`_INVENTORY_UNIT_LABEL`, 업계 관행 하드코딩) | 재고량이 0 또는 None이면 생성 안 함 |
| `inventory_change_pct` | 재고량 등락률 | `(최신재고-직전유효재고)/직전유효재고 × 100` | observations | % | 직전 유효 재고 관측치가 없으면 생략 |
| `compare_overall_change_pct` | 비교광종 대비 조회기간 변화율차 | `(주계열 전체변화율 - 비교계열 전체변화율) × 100` | `compare_mineral`/`compare_observations` | %p | `compare_observations` 없거나 두 계열 중 하나라도 관측치 2건 미만이면 생략 |
| `annual_return_YYYY` | [연도]년 수익률 | 그 해 첫 관측가→마지막 관측가 변화율 | observations | %(detailed_metrics 전용) | 그 해 관측치가 1건뿐(변화율 계산 불가)이면 생략, 실제 커버리지 340일 미만이면 라벨에 "(연중)" 부기 |
| `seasonality_month_MM` | [월]월 평균 수익률 | 그 달(모든 연도)의 (그 달 첫 관측가→마지막 관측가 변화율) 평균 | observations | %(detailed_metrics 전용) | 어느 해에도 데이터가 없는 달은 생략; 최대 표본수 1(=2개 연도 이상 걸치지 못함)이면 별도 안내 문구(`insufficient_history`)에 참고용으로 명시 |

**입력 필드 보충**: `price_position`(백분위)·`price_momentum`(RSI)·
`ma_trend`(이동평균 배열)·`relative_value`(상대가치)·`inventory_context`
(재고 백분위·동행비율)는 문장(claim)에만 실리고 key_metrics 표에는 없다
— 예외 기준은 `01_메뉴별_최종_답변_템플릿.md`의 해당 조건부 항목 참고
(각각 관측치 20/15/(이동평균 창 중 2개 이상)/20/10건 미만이면 미계산).

## 공통 예외처리 원칙(전 page_id)

- **데이터 조건 미충족(관측 1건뿐·국가 3개 미만·총액 0 등)**: 계산기가
  `ValueError`를 던지면 `summary.py::_calculate_or_no_data`가
  `DataSourceError`로 변환해 응답 status를 `NO_DATA`로 만든다
  (`INTERNAL_ERROR`와 구분 — 코드 버그가 아니라 정당한 데이터 부족).
- **부분 계산 불가**: 개별 지표 하나가 계산 불가능하면(예: 직전 관측치
  없음) 그 지표만 조용히 생략하고 나머지는 정상 계산한다 — 페이지 전체를
  NO_DATA로 만들지 않는다.
- **key_metrics 상한**: `KEY_METRICS_MAX_COUNT`(14)를 넘으면 뒤쪽 항목이
  잘린다 — `_capped_key_metrics`(komir_summary.py 4종 계산기, indicator
  2종)는 잘릴 때 경고 로그를 남기고, `calculate_composite_summary`(frozen)
  는 `[:8]`로 조용히 자른다(로그 없음 — frozen 파일 제약).
- **경고 채널 2종**: `warnings`(내부 로그 전용, 독자 응답에는 절대
  노출하지 않음, `report_render.py` SC-016 결정)와 `EvidenceClaim`(독자가
  보는 문장, "계산하지 않았습니다" 류 명시적 안내) — 사용자가 명시적
  안내를 선택해(2026-08-31) 위 산출표의 "예외처리 기준"에 해당하는
  대부분의 생략은 `01_메뉴별_최종_답변_템플릿.md`의 대응 조건부 문장으로
  독자에게도 드러난다.
