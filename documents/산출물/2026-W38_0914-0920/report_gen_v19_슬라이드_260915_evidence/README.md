## 2. 재현·검증

```
KOMIR_ROOT=/path/to/komir python3 <이 폴더>/refetch_v19_sources.py   # 입력은 아래 스냅샷만 v18과 다름
KOMIR_ROOT=/path/to/komir python3 <이 폴더>/build_v19_full.py        # v10.pptx 복사 → v19.pptx, v18.pptx 대비 적색
```
- **입력 교정(스냅샷)**: v13~v18은 교차비교용 `komis_snapshot_response`로 정적 덤프
  `동|생산량|map`을 썼는데, 이 덤프는 2019~2025 다년 조회라 KOMIS가 기간 합산값을 준
  응답이다(`models.py` 필드 docstring의 "단일 연도 전제" 위반 — 그래서 v17/v18 슬라이드에
  "호주 생산량 8위(약 575만톤, 4.35%)"가 찍혔다). v19부터 같은 덤프의 chart 응답(행마다
  매장량·생산량 둘 다 있음)에서 2025년 행만 골라 단일연도 스냅샷을 만든다 → 호주 약
  73만톤·3.17%(발주처 템플릿과 일치). 생산량 슬라이드에도 매장량 스냅샷을 넣었다(v18까진
  없어 교차비교 문장이 아예 없었음).
- `v19_sources.json` vs `v18_sources.json`(request_id 제외) 차이: `map_mineral_baseline_full`·
  `map_mineral_production` 2건뿐(core 3→4문장, major 10→12/9→12문장). 나머지 19건 동일.
- 저장된 v19.pptx: 적색 6곳 = 슬라이드 20(매장량)·21(생산량)의 본문 문단 2(추세)·
  4(순위 표기·CR3 해석·비율 2문장)·6(변동폭). 템플릿 잔존 적색→흑색 67 run.
- 분량: 본문 약 1,650자(v18 약 1,400자), 9pt·6.6in 상자 기준 추정 32줄 ≈ 4.8in(상자 top
  2.1in → 6.9in, 슬라이드 7.5in 안). LibreOffice가 없어 렌더링 실측은 못 했다 — PowerPoint
  에서 넘침 확인 필요. 넘치면 8pt로 내리거나 매장량/생산량을 각 2장으로 나누는 것이 대안.
