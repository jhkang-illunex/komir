## 2. 알려진 데이터 공백(코드 문제 아님)

이번 세션에서 실측으로 확인된, **코드는 정상이지만 dev-dummy 데이터 자체가
비어 답을 못 만드는** 케이스 — 실데이터 적재 시 별도 코드 수정 없이 바로
해소된다.

1. `KO_CSTM_CMMRC.EXP_AMT`/`EXP_WEIG`(국내 수출) — 확인한 모든 광종(니켈·
   구리·리튬)에서 전부 0. 수입(`INCM_AMT`)만 채워져 있음.
2. `KO_UN_CMMRC`(세계 교역, UN Comtrade) — dev-dummy 행의 HS코드가
   `ai_hs_mnrl_map`(광종→HS코드 매핑)과 전혀 안 겹쳐, 광종 무관 항상 0건.
3. `indicator_market`/`indicator_supply`/`indicator_composite` — private
   프로필 전용 제약은 데이터 공백이 아니라 의도된 접근제어(2026-09-01
   사용자 지시).

## 3. 남은 후속 과제(미착수)

- **D2**: 조회기간이 범위 밖인데 komis_raw가 부분(넓은 단위) 데이터를
  반환하면 결정적 기권 대신 근접제안으로 새는 문제 — 사용자 판단으로 보류.
- **가격예측 비교랭킹**(`KO_MNRL_PRC_PREDC`) — RDB 후보리스트 2순위 중
  미구현 1건, 기존 `komis_indicator_ranking`과 같은 패턴이라 착수 용이.
- **map_global 국가 랭킹**·**국내 수출 랭킹** — 데이터 공백 해소 대기
  (§2-1·§2-2), 실데이터 적재 시 별도 확인 없이 바로 동작 예상.
- **page_recommend 메뉴 경로 정확도** — 이번 세션 범위 밖, 미검토.
