# 챗봇 멀티턴 대용어(anaphora) 처리 실측 테스트 (2026-09-17)

> 대상: `/pubchat`(컨테이너 `komir-rag-chat-test`, 이미지 `komir-rag-chat:260917-nearmiss-prune2`,
> 같은 날 반영된 근접제안 가지치기 수정 포함). 방법: 세션 유지(`session_id` 재사용)로 3~5턴
> 대화 10개 시나리오를 실제로 실행하고, 각 턴에서 대용어("그거"·"그 가격"·"그 나라" 등)가
> 직전 답변이 확정한 대상으로 올바르게 풀리는지, 새 개체 언급 시 맥락이 정확히 전환되는지,
> 기권/무관 질문이 끼어들어도 맥락이 깨지지 않는지를 확인했다. 판정은 각 턴의 실제 응답과
> 인용 출처를 직접 읽어 사람이 매겼다(자동 채점 아님).

## 상세 로그

### S1 가격 대용어 + 기간 확장 (3턴)
1. Q: 니켈 가격 알려줘 → 니켈 가격 표(2026-09-02~09-08).
2. Q: 그 가격 최근 한 달 추이는 어때? → "그 가격"=니켈로 정확히 해소, 기간도 한 달로
   자동 확장(2026-08-17~09-08, 17건). **PASS**.
3. Q: 작년 이맘때보다 어때? → "작년 이맘때와 비교한 니켈 가격 자료는 없습니다"로 정직하게
   답하고 2025-10-09~12-31 데이터를 근접제안. 개체(니켈)는 여전히 정확하나, "전년 동기
   비교" 자체를 계산하는 기능이 없다(제안된 기간도 "이맘때"와는 어긋남) — **대용어 문제가
   아니라 별도 기능 공백**으로 기록.

### S2 소재 전환 후 명시적 복귀 (4턴)
니켈 → 코발트(명시 전환) → "그거"(=코발트, 니켈로 안 돌아감) → "니켈은 다시"(명시 복귀).
4턴 모두 정확. **PASS** — "최근 답변이 확정한 대상을 우선한다" 규칙이 기대대로 동작.

### S3 비교쌍 대용어 (3턴)
1. "니켈이랑 코발트 가격 비교해줘" → 비교표 생성(다만 KO_MNRL_PRC 현재가가 아니라 dense
   문서의 2026년 전망가를 씀 — 별개 관찰 포인트).
2. "그 둘 중에 최근 더 오른 건?" → "비교 자료 없음"으로 기권성 답변, 무관 근접제안.
3. "그 반대는 얼마나 내렸어?" → 동일 패턴.
"그 둘"이 니켈·코발트를 가리킨다는 것 자체는 문제 없어 보이나(전혀 다른 광종 근거를
들이대지 않음), 이미 1턴에서 두 광종 가격을 각각 조회했으면서도 "어느 쪽이 더 올랐나"를
그 데이터에서 계산해 답하는 기능이 없다. **대용어 해소는 의심할 근거 없음(PARTIAL), 비교
연산 기능은 공백(별도 이슈로 기록)**.

### S4 국내수입 대용어 + 국가필터 (3턴)
1. "동 수입 현황 알려줘" → 국가별 표(남아프리카공화국 1위로 나옴 — 더미 데이터 특성).
2. "그 중에 칠레 비중은 얼마야?" → "자료 없음"이라며 같은 전체 표를 다시 제안. 광종(동)
   맥락은 유지되나, 이미 받은 국가별 표에서 칠레 행을 뽑아 비중을 계산하는 기능이 없다.
3. "작년이랑 비교하면 어때?" → 동일하게 계산 기능 부재로 근접제안.
**PARTIAL** — 대용어(동) 해소는 맞고, "부분 조회·비중 계산·전년비"류 파생 질문에 답하는
능력이 빠져 있다.

### S5 세계교역 광종 전환 (4턴)
1. "리튬 수출 현황 알려줘" → 조회 결과 없음(no_data_for_period, 이 환경 데이터 특성).
2. "그 중 1위 수입국은 어디야?" → 실패한 1턴인데도 "리튬"이라는 개체는 살아남아, 리튬
   수입 기준 1위 수입국(중국)을 정확히 답함. **PASS**(개체가 실패한 턴에서도 유지됨).
3. "코발트는 어때?" → 코발트로 전환(문서 근거 기반 시장상황 답변으로 형식은 달라짐).
4. "그것도 1위 수입국 알려줘" → "그것"=코발트로 정확히 풀고, 3턴의 답변 형식(dense
   문서)과 무관하게 "1위 수입국" 질문 의도를 살려 구조화 데이터로 다시 답함(인도네시아).
   **PASS** — 개체 전환과 질문 의도(필드) 승계가 각각 독립적으로 정확히 동작.

### S6 오프토픽 끼어들기 후 복귀 (3턴)
니켈 가격 → "오늘 날씨 어때?"(0.4초, 즉시 `off_topic` 기권) → "다시 그 가격 알려줘"(니켈로
정확히 복귀). **PASS** — 무관 질문의 즉시 차단이 다음 턴의 맥락을 손상시키지 않는다.

### S7 모호한 대용어 — 광종 미특정 (3턴)
"가격 데이터 보여줘"(광종 없어 `ambiguous` 기권, "기간·정보 유형을 지정해 주십시오") →
"니켈로 보여줘"(정확히 복구) → "최근 일주일치만 보여줘"(니켈 맥락 유지 + 기간 정제 동시
적용). **PASS**.

### S8 장기 체인·최신 우선 (5턴)
동 → 리튬(전환) → "그 가격 최근 추이는?"(=리튬, 동으로 안 돌아감) → "동은 다시
어때?"(명시 복귀) → "아니 방금 전에 말한 리튬 거 말한거야"(직전 답변이 아니라 **두 턴
전** 언급을 가리키는 정정 표현도 정확히 리튬으로 해소). 5턴 전부 **PASS** — 이번 테스트
중 가장 까다로운 케이스였는데도 깨지지 않았다.

### S9 필드 전환 — 매장량 ↔ 생산량 (3턴)
동 매장량 → "생산량은?"(광종 동 유지, 필드만 전환) → "리튬도 알려줘"(광종을 리튬으로
바꾸면서 매장량·생산량 **두 필드 모두** 승계해 함께 답함). **PASS** — 필드 승계까지
정교하게 동작.

### S10 상관관계 혼입 후 복구 (3턴)
동 매장량 → "그거랑 오늘 날씨랑 상관있어?"(0.4초, `off_topic` 즉시 기권 — 어제 수정한
근접제안 가지치기+오프토픽 차단이 "그거"로 유효 개체를 가리키는 질문에도 정상 작동) →
"그럼 그냥 그 매장량만 다시 보여줘"(동 매장량으로 정확히 복구). **PASS**.

## 결론

- **대용어 해소 메커니즘 자체는 견고하다.** 개체 대체("그거"→직전 답변 대상), 최신 우선
  원칙(오래된 턴이 아니라 가장 최근 확정된 대상), 명시적 전환·복귀, 두 턴 전 언급을
  가리키는 정정 표현, 무관 질문 개입 후 복구, 필드(매장량/생산량, 수입/수출 1위국) 승계까지
  실측 10개 시나리오에서 실패 없이 전부 확인됐다.
- **실패가 아니라 별도로 기록할 공백 2건**: 이미 조회한 두 대상을 놓고 "어느 쪽이 더
  올랐나"(S3), 표 안에서 특정 국가만 뽑아 비중·전년비를 계산(S4)하는 **파생 연산**은
  현재 근접제안으로 빠진다. 대용어는 정확히 풀렸으므로 이건 라우팅/생성 쪽의 별개
  기능 공백이다 — 필요하면 별도 작업으로 다룰 것.
- 이번 테스트는 `documents/meta/WORKLOG.md`에는 기록하지 않았다(코드 변경이 없는 검증
  활동). 코드 변경이 필요하면(S3/S4 공백 대응 등) 별도 지시 시 진행.
