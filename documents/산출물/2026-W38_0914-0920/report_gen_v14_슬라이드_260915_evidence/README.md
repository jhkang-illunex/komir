## 3. 적색 표시 방법(`build_v14_full.py::mark_diff_red`)

전부 채운 뒤 실제 `v13.pptx`를 열어 같은 슬라이드·같은 도형 이름·같은
문단 순번(표는 같은 행 라벨·열)의 텍스트를 대조한다.
- 달라진 문단은 공백/비공백 토큰 단위 `difflib` 대조로 **바뀐 토큰만**
  적색(FF0000) run으로 쪼갠다. 첫 run의 rPr을 복제하므로 글꼴 크기·굵기는
  이웃 문단과 동일하게 유지된다(검증: 문단 내 run 6개 서식 집합 1종, 이전
  문단과 동일).
- 표 셀·제목·캡션은 달라지면 셀 전체 적색, v13에 없는 표 행·문단은 통째로
  적색(이번엔 해당 없음).
- **템플릿 잔존 적색 → 흑색 통일**(`clear_inherited_red`): v10 템플릿부터
  슬라이드 14~21 "표 6" 일부 셀에 적색(FF0000) 글꼴이, 슬라이드 13
  수급동향지표 "표 10" 전체에 진적색(C00000) 글꼴이 박혀 있어 v13까지
  그대로 물려받았다(FF0000 35 run·C00000 26 run, 텍스트는 v13과 동일한
  셀). 사용자 지시("기존에 있던 적색은 다 흑색으로 통일, v13·v14 결과에서
  차이 나는 부분만 v14에서 적색")대로 대조 전에 둘 다 000000으로 바꿨다
  (67 run, 빈 run 6개 포함). v13.pptx는 손대지 않았다.
