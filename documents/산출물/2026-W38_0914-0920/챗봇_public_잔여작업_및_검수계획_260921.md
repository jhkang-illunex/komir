# 챗봇 Public 잔여 작업 및 검수 계획

기준일: 2026-09-21 KST  
대상: `rag_chat`의 public API(`/pubchat`, `mode=auto`)  
평가 기준: `챗봇-응답품질-평가_260916.xlsx`의 Q01~Q30, 최초 응답 1회. Q23→Q24→Q25만 동일 세션으로 실행했다. 스크린샷/브라우저 렌더링은 이 환경에서 수집하지 않고 SSE 본문·인용·표·차트 이벤트로 평가했다.

## 최신 확인 결과

- 1차 public 전수 재평가: 통과 5 / 부분 7 / 실패 18 (16.7%)
- 수치·HS·순위 메타데이터 1차 수정 후: 통과 7 / 부분 8 / 실패 15 (23.3%)
- 이후 비중 차트의 `%` Y축 오류와 비교표 날짜 Y축 혼입을 수정했으나, 이 수정본에 대한 30문항 전수 재집계는 아직 수행하지 않았다.

완료·확인된 수정:

- public에서 private 전용 지표 요청은 무관 문서 검색으로 우회하지 않고 기권한다.
- 미확인 `수입수요 예측` 메뉴는 추측 추천 대신 메뉴 경로 미확인 안내를 반환한다.
- HHI는 상위 일부 행이 아닌 전체 국가 모집단으로 계산한다. 니켈 수입 HHI는 전체 10개국, 합계 369,200,000 USD, HHI 2327.98로 DB 독립 검산과 일치했다.
- 명시 HS 코드 질의는 광종 추측으로 다른 HS/광종을 치환하지 않는다. Q14의 HS 2603000000 오귀속은 해소됐다.
- 생산/매장 국가순위는 통계연도·톤 단위·`total` 단일 계열을 전달한다.
- 교역 비중 차트는 `share_pct` 단일 계열과 `%` 축을 사용한다.

## 이번 보충 구현 범위

사용자 결정에 따라 아래 두 기존 집계 경로만 보강한다.

1. 광산 문서 기반 집계 (`mine_aggregate`)
2. 국가별 교역 순위·RDB 집계 (`fetch_country_ranking`, concentration 및 관련 원천 조회)

제외:

- 개념 설명·가정 시나리오 답변 경로(Q15, Q17~Q22)
- 위기진단 정본 연결(Q08~Q09)
- 광종별 광물종합지표의 제품 정의(Q02)
- 최신 지정학 사건 원문 데이터(Q16)
- 최신 60행 가격 표시 정책(Q01)
- private 데이터 우회, `STRUCTURED_ENABLED` 재활성화, expired 파이프라인 재도입

## 검수 절차

1. 구현 담당자가 제한된 집계 경로와 회귀 테스트를 수정한다.
2. 테스트 컨테이너를 재빌드·재기동하고, 실행 컨테이너의 소스 해시를 작업본과 대조한다.
3. public `/pubchat`에서 Q05, Q06, Q11, Q13, Q14, Q24, Q25, Q29을 우선 재검증한다.
4. 수치 답변은 표·본문·차트 이벤트와 독립 SQL/계산 결과를 대사한다.
5. Q23→Q24→Q25는 동일 세션 회귀로 확인한다.
6. 범위 항목이 안정화되면 Q01~Q30 전체를 최초 응답 기준으로 재집계한다.

## 현 제약과 종료 조건

- 현재 제외된 Q01, Q02, Q08, Q09, Q16이 모두 미충족이면 원본 30문항 기준의 이론상 최대 통과 수는 25/30(83.3%)이다.
- 따라서 이 범위만으로 90%를 선언하지 않는다. 90% 목표는 제외 항목의 정책·제품 정의·정본 데이터 연결 여부를 별도로 결정한 뒤 재협의한다.
- 완료 보고에는 통과/부분/실패 수, 변경 전후, 남은 제약, 사용한 SSE·SQL 검증 근거를 함께 기록한다.
