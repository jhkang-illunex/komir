## 2. 재현·검증

```
KOMIR_ROOT=/path/to/komir python3 <이 폴더>/refetch_v17_sources.py   # 입력·절차 v16과 동일
KOMIR_ROOT=/path/to/komir python3 <이 폴더>/build_v17_full.py        # v10.pptx 복사 → v17.pptx, v16.pptx 대비 적색
```
- `v17_sources.json` vs `v16_sources.json`(request_id 제외) 차이: `map_global_export_full`
  current_position 문장 1건뿐(수입 baseline·국가필터 슬라이드는 route_yearly_trend가
  있어 이 문장이 애초에 안 내려옴). 나머지 20건 동일.
- 저장된 v17.pptx를 v16.pptx와 독립 대조: 텍스트 키 집합 동일, 다른 위치 1곳
  (슬라이드 18 "TextBox 4" 기간 변화 문단) = 적색 문단. 저장본 명시 색상 FF0000 1,
  000000 243, 테마색 31333F 449 — 그 외 적색 없음.
- **표시 방식 주의**: 이번 변경은 접두어 *삭제*라 새로 생긴 토큰이 없다. 삭제된
  텍스트는 적색으로 보여줄 수 없어 `mark_diff_red`의 폴백(바뀐 토큰이 하나도 없으면
  문단 전체 적색)대로 그 문장 전체가 적색이다 — 문장이 바뀌었다는 표시이지 문장
  전체가 새 내용이라는 뜻은 아니다.
