## 2. 종합 판정

**PASS 8 / PARTIAL 2 / FAIL 4 / 판정보류·재검증필요 2** (총 16케이스)

기존에 이미 알려져 있던 한계(B4·C3, 데이터 자체가 코퍼스에 희소)는 회귀 없이
그대로였고, **오늘 처음 확인된 새 문제는 B2·D2·D4 세 건**이다:

- **B2**: "수입 상위 N개국+비중" 같은 순위·비중형 질문이 `komis_raw`
  domestic_trade/global_trade topic으로 안 켜짐 — ROUTE_PROMPT가 이 topic을
  "국가별 수입/수출 물량·금액"으로만 설명하고 "상위 N개국 순위"라는 표현은
  명시적 예시가 없어서로 추정.
- **D2**: 조회기간이 완전히 범위 밖(2010년)일 때 komis_raw가 일부(연간) 데이터를
  돌려주면 verify가 "불충분"으로만 보고 결정적 `no_data_for_period` 경로로
  못 빠짐 — reformulate가 대신 돌아 엉뚱한 대체 문서로 귀결.
- **D4**: "니켈 데이터 보여주세요"류 모호 질문이 모호-판정 경로를 안 타고
  정상 검색 경로로 흘러 무관한 옛 데이터로 답변. `komis_topic=None`인데
  `use_komis_raw=True`인 모순 조합도 관찰됨(ROUTE_PROMPT 스키마 일관성 문제).

세 건 다 오늘 오전에 고친 멀티소스 timeout/dedup/OKF/복합질문 버그와는
무관한 **기존부터 있던 별개 결함**으로 보인다(관련 코드 경로가 다름 — B2/D2/D4는
`ROUTE_PROMPT`의 komis_topic 판단·`VERIFY_PROMPT`의 부분데이터 처리 로직이지,
오늘 고친 병렬조회/dedup/OKF/복합질문-분기 로직이 아님). 다만 오늘 VERIFY_PROMPT를
건드렸으니 **완전히 무관하다고 100% 단정하기보다는 별도 조사로 확인 권장**.
